## 0. 本轮三条硬要求（Eason 定案）

1. **产品树不再常驻弹窗底部**——改为「更换/添加产品」时按需弹出的浮窗。
2. **主分析产品 = 唯一的一款产品 + 唯一型号 + 唯一颜色**。把一个产品的全部型号加进来时，
   每个型号各成一张独立主分析卡，不允许一张卡里挂多个型号（截图圈红的「配置行」形态废除）。
3. 主品与对比条目都要有**显著的替换入口**（树收进浮窗后，入口必须在条目本身上）。

附加定案：树形筛选器的「逐层连贯切换」理念搬进条目显示本身——点显示文字的某一段，
就在那一层快速切换，不必从头重选；「整系列」快捷删除；「全部型号」保留但语义改为
**每型号一张卡 / 每型号一条对比**；颜色不进树浮窗，只在已选条目上换。

## 1. 数据模型收敛：卡 = 单产品·单型号·单颜色

```ts
interface MainProduct {
  id: string;                    // 稳定键（拖拽换序/浮窗定位），与 modelId 解耦
  main: ProductSelection | null; // 唯一主品（含颜色 skuIds）；null = 未选主品的「空对」
  compares: ProductSelection[];  // 本卡对比区
}
```

- 现结构 `{ modelId, configs[], compares }` 退役；`configs` 收敛为单数 `main`。
- 「＋全部型号」= 逐配置建卡（每卡 1 配置），不再并进一张卡。
- 配额：每卡 **1 主品 + ≤7 对比 = 8 条线**（main 为空的卡对比 ≤8）；
  **卡数上限 8**（= 分离面板数上限，批量动作按剩余名额截断）。
- 连带：`cardQuota`（=7 常量）、`autoComparesFor/reapplyAuto`（按单配置取矩阵）、
  `flatSelections`、`groupToCards`（不再按型号并卡——URL 每项本就是单配置语义）、
  PriceTrend panelData（卡 → [main, ...compares]）、VolumePrice defaultSlots、
  tierSelection、AlertsPage/MarketMap 的 setMains 构卡，全部按新形适配。

### 持久化 v11 → v12

| 旧 | 新 |
|---|---|
| v11 卡 `{modelId, configs[], compares}` | 首配置卡继承 compares；其余配置卡：autoMatch 开 → 按矩阵自动补，关 → 空对比区 |
| v10 | 先走现有 migrateV10，再按上行展开 |
| URL `main=modelId__romram,…` | 语义不变（本就单配置），解析改为**每项一卡**（同型号两配置 = 两卡，不再合并）；空对不进 URL（仅本地持久化） |

## 3. 主分析产品：显示即入口的分段连贯切换

左区一行显示四段，**每段本身可点**，点开的是「从该层向下续选」的树浮窗
（= 产品树的切片，预定位当前路径；hover 出浅蓝底提示可点）：

```
┌ 主分析产品 · 单选 ─────────────────────────────────────┐
│  ● HUAWEI   Pura 90s Pro Max   [12+256 GB]   [Black]   │
│    ↓点           ↓点               ↓点          ↓点     │
│  品牌层           产品层            型号层        颜色    │
│                                              [更换] [×] │
└─────────────────────────────────────────────────────────┘
```

| 点哪段 | 弹出什么 | 选完发生什么 |
|---|---|---|
| **品牌段**（●HUAWEI） | 完整树：品牌→系列→产品→型号 4 列 | 整卡替换；型号/颜色按映射规则保留（下）；对比区原样不动 |
| **产品段**（Pura 90s Pro Max） | 3 列：**系列→产品→型号**（首列=当前品牌全部系列，当前系列高亮） | 同上；点「Mate」即跨系列、再点具体产品落地——「点 Pura 切 Mate」走这里，一次浮窗内完成 |
| **型号段**（12+256 GB） | 1 列：该产品全部配置（当前高亮） | 同产品换型号；同色存在则保同色，否则默认最低价色 |
| **颜色段**（Black） | ColorFlyout（不进树，符合定案5） | 换色/多色均价，即改即存 |

- 映射规则（沿用 mapConfigsToProduct，金测锚定）：换品牌/系列/产品时
  型号=同 romram 优先→回退首个；颜色=同名同色优先→回退最低价色；对比区不动。
- **[更换] 按钮**：行尾显性入口，点开 = 品牌段同款完整树浮窗——不依赖用户
  「发现分段可点」，满足「显著位置」要求；两入口同源同行为。
- **[×]**：删除整对（主品+其对比区），语义与现状一致。

四个浮窗共用一个组件：`LevelSwitchPopover({ fromLevel, context })`，
内部复用 CascadePanel 列构造（现弹窗 columns 逻辑改为按层级裁剪 + 初始 path）。

## 4. 对比产品：五点逐条落法

| # | 要求 | 设计 |
|---|---|---|
| 1 | 快速匹配有显式按钮「自动匹配竞品」 | 分界线圆钮升级为**带字按钮**：⚡ 图标 + 「自动匹配竞品」（56×44 圆角块、文字 10px 两行），华为主品实底蓝可点、非华为置灰带提示（语义不变：按矩阵重算本卡对比区）。全局动作行「全部自动匹配」+「对比自动跟随」开关保留 |
| 2a | 无任何条目时有手动添加触发 | 对比区空态显示「＋ 添加对比产品」虚线块（主品未选也允许先加——挂到空对上，见 §5 场景1） |
| 2b | 有条目后新增触发样式与空态一致 | 「＋ 添加对比产品」虚线块**常驻对比区末行**：空态=唯一内容，有态=列表最后一行，同一组件同样式；点开 = 树浮窗（对比上下文：行尾「＋对比」可连点，配额满置灰） |
| 3a | 删除 | 每条行尾 [×]（现状保留） |
| 3b | 修改是否与主品一致 | **建议：完全同构**。对比条目同样显示 品牌·产品·型号·颜色 四段（12px 小一号），段段可点开同款层级浮窗 + 行尾 [更换][×]。理由：交互语言全弹窗统一、学一次到处用；对比区的「弱」靠白底灰框/灰字/密度表达，不靠砍编辑能力 |
| 4 | 快选只限单产品多型号 | 「＋全部型号」保留：对比上下文=该产品全部配置逐条入区（受配额截断、跳过与主品同配置）；主品上下文=每配置一张卡。**「整系列」删除**——系列行只作下钻 |
| 5 | 颜色不进树浮窗 | 树浮窗删除颜色列/色块：点型号行即以默认最低价色落选；换色只在已选条目的颜色段（ColorFlyout） |

## 5. 两个场景走查

### 场景 1 · 默认新增状态（进来时什么都没选）

```
┌对(空)─────────────────────────────────────────────────────┐
│ ┌主分析·单选──────────────┐    ┌对比产品·可多选 0/8─────┐ │
│ │                         │ ⚡ │                        │ │
│ │    ＋ 选择主分析产品      │ 置 │  ＋ 添加对比产品        │ │
│ │   （点开产品树浮窗，      │ 灰 │ （可先于主品手动添加）  │ │
│ │     点型号行即建对）      │    │                        │ │
│ └─────────────────────────┘    └────────────────────────┘ │
└────────────────────────────────────────────────────────────┘
```

- 左块大虚线触发 → 完整树浮窗：点型号行 = 建卡落选；产品行「＋全部型号」= 每配置一卡。
- ⚡ 置灰 + 提示「先选主分析产品」；选定华为主品后亮起，autoMatch 开即自动填右。
- 右侧允许**先加对比**：生成一张 `main=null` 的空对挂着（图表照常画这几条线）；
  之后补选主品，对比区原样保留。空对不进 URL 分享。
- 上方「最近」组合若有记录，一键带出上次搭配——首选的快速路径。

### 场景 2 · 已选状态的修改与删除

| 动作 | 路径 |
|---|---|
| 换型号（微调） | 点型号段 → 单列浮窗点选，即换 |
| 换产品/跨系列 | 点产品段 → 系列→产品→型号 浮窗；或点品牌段/更换 → 完整树 |
| 换颜色 | 点颜色段 → ColorFlyout |
| 删主品 | 行尾 [×] = 删整对（含对比区） |
| 加对比 | 对比区末行「＋ 添加对比产品」（与空态同样式） |
| 改对比条目 | 分段点击/[更换]，与主品同构；约束保留：不与主品同产品（防自身对比） |
| 删对比条目 | 条目行尾 [×] |
| 调顺序 | 拖 ⠿ 把手（= 分离面板顺序，现状） |
| 一键重来 | 「更换」换主品不动对比区；「全部自动匹配」回矩阵口径 |

## 6. 树浮窗规格（唯一一份，四处入口）

- 入口：空对左块 / 行尾 [更换] / 「＋ 添加主分析产品」 / 「＋ 添加对比产品」。
- 结构：搜索框（顶部，保留）+ CascadePanel 列（按上下文与起始层级裁剪，
  列宽沿用内容自适应+不截断；高 ~340 固定，Popover 承载、锚定触发处）。
- 型号列行尾动作按上下文：主品上下文 = **点击行即选定**（单选语义）；
  对比上下文 = 「＋对比 / ✓对比」可连点（现状交互）。产品列行尾「全部型号」两上下文都在。
- 初始定位：有源卡 = 其当前品牌/系列/产品路径；无源 = 华为首个在售型号。
