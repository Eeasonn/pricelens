量价走势（结论看板）× 量价预测（推演看板）

把「从分析到推演」的完整链路落成两个界面：量价走势只放已经发生的事实与结论，量价预测把结论作为输入向后延伸 1–2 个月。现有量价操作底座（一线日常看数）保持不动，本稿两页是叠加在其上的结论层与推演层。

0 · 讨论要点 → 设计落点对照

讨论拍板 / 要点设计落点
看板分左右：左边全是结论（事实），右边才是预测；预测永远只向未来拆成两个页面：量价走势 = 左边（结论）、量价预测 = 右边（推演）；走势页时间选择器只能回看历史，预测页主图右半恒为未来 8 周
顺序：先大盘 → 价格（策略+影响）→ 量价 → 库存 → 成本销毛走势页五张看板自上而下按此顺序；预测页因子区同序（大盘全宽一行，库存/成本销毛各半）
结论直接写在看板上（领导直接看结论，不进 Agent 侧边栏）每卡右侧固定「结论」栏，每条带类型标：●数据（图上可证）、●资讯（确定性新闻）、●分析（推断）
视觉重心 = 量价主图；底部小图放各考量来源，且都要有历史+未来预测页主图占首屏视觉重心（销量柱+价格线+参考线+把握区间），因子区在下方，各自小图历史实线/预测虚线
信任问题：下面小图怎么影响上面，必须能看见；允许看每个时点的考量比例①因子区可调（拖板/开关/事件），主图与摘要实时联动；②悬停预测任意周，浮窗列出该周「本周考量」构成（大盘/档期/竞品/资源 各自影响幅度）
权重随时间变化，单时点可改；直接改结果必须绑定原因点预测柱 → 微调浮层：新值 + 调整原因必填（不填无法保存），应用后图上留手调标记、纪要留痕
因子与约束的区别体现在「把握」上，不向领导解释术语不用「置信区间/因子/约束」字样：库存修正标把握大 ±2%（区间窄）、成本与大盘标把握中 ±8%（区间宽），主图预测柱画区间帽，宽窄即语义
预测先得「市场口径」结果，再用库存刚性压到「可售口径」主图画两条：细虚线=不含库存限制，主柱=按可售库存；W50 起分叉段琥珀着色+锚点，缺口进摘要条
参考对象必须露出：不管参考谁，一定要画出来走势页量价图画 Mate 80 上市同期；预测页主图把 Mate 80 已发生历史按同周龄贯穿 W37–W52；卡头固定露出主参考，竞品事件参考可在弹窗改选
事件（如竞品上市）输入后自动推荐历史对标，推荐不对可改选「添加事件」→ 对标弹窗：推荐「iPhone 17 Pro 上市 × Mate 80 同期」迷你图与影响读数（−9% · 3 周），可改选 16 代 × Mate 70，并调整影响幅度/周期后套用到预测
两代同跑：新代销量未过阈值前，价格对标以旧代为准预测页「竞品对标」卡：18 Pro 周销 2.1 万 = 17 代同期 62%（阈值 70%）→ 当前对标 iPhone 17，过阈值自动切换
大事件（如折叠屏阵营）单拎，与常规迭代区分事件分三类徽标：大促（琥珀）/竞品（蓝）/大事件（墨）；大盘面板内置示例开关
库存卡：库存柱 + 渠道 DOS 线 + SI 供应时点；DOS 会虚高，必须与库存同看；不看 SO走势页库存卡 = 库存柱 + 渠道 DOS 线 + 全流程 DOS 虚线 + SI ▼标记；结论栏给「Pura 90s 库存 −38% 但 DOS 51→69 天」的虚高警示；渠道缺货用 DNS 钻取点（悬停出，非常驻）
成本销毛 = 柱子加折线（成本趋势+销毛）；成本按月版本走势页成本销毛卡与预测页成本因子卡均为：月版本成本阶梯线 + 周销毛琥珀柱
资源投入作为额外变量，用户自己填、自己判定预测页「资源投入」卡：低/标准/加强三档 + 自填备注，仅作用于销量乘子
开完会调半天，图+考量+调整记录截图即会议结论页面底部「推演纪要」时间线：每次操作自动留痕（谁/改了什么/为什么），配「生成本期预测纪要 / 另存情景」
（11-03 下午新增）领导操盘实证：先看谁份额高、再看品牌下哪个品卖最好，Top 品自带价格心智 → 翻页对照走势页新增「品牌与 Top 品」卡：品牌份额走势（月）+ 各品牌 Top 品（传播名/周销/份额/4 周趋势）——大盘从「只有总趋势」补齐「品牌 → 品」两层
（新增）想知道谁在领跌/领涨大盘：剔除品牌 X 后的大盘同比 vs 全大盘，剔除后明显好转 = X 领跌大盘卡「领跌拆解」：各品牌对大盘同比的贡献条（谁跌最多）+ 点击品牌即做剔除验证，读数直接给结论（领跌 / 主要拖累 / 普跌 / 逆势上涨）——GFK 里很长的逻辑链一步到位
（新增）大盘要看同比：Q4 只能 vs 去年 Q4，季度环比天然不公平（PCT、博总均确认）大盘主图小柱由周环比改为同比（vs 2025 同周），口径条同步标注；「环比 = 近 4 周均 vs 前 4 周均」显性化（领导对该口径有认知偏差，最终口径待拍板）
（新增）自家品档位重叠互相挤占（GT 7 Pro × Watch 6），领导明确关注；推演时要把两个自家品放一起看影响预测页新增「自家挤占」卡：两款自家品对照小图（手机 Mate 90 × Pura 90s / 穿戴 GT 7 Pro × Watch 6 双场景切换）+ 挤占读数 + 承接修正开关（W45–W48 +2% 联动主图）；把握低 ±12%（挤占最难量化，区间最宽）
（新增）领导确实关注 DOS 和 inventory印证走势页库存卡设计：库存柱 + 渠道 DOS + 全流程 DOS + SI 保持
（新增）ASP 大家都熟 GFK 口径，没必要自己设计不做：不自造 ASP 指标，价格卡沿用品牌均价（GFK 同口径）
定位口径（应对「OVS 和 GFK 已经 more than enough」）：看板不是替业务做决定，而是把 GFK 里要走很长链路的判断（剔除验证、量价对照、事件对标）变成一步，解放业务精力去解决真正难解决的问题。

1 · 因果模型（界面背后的口径）

左：输入（考量来源，蓝=参考型考量、琥珀=硬性约束）；中：价格与销量两条链；右：加权汇成销毛。输入即走势页六张看板、预测页因子区的来源。
  • 参考型考量（大盘与档期、竞品策略与事件、成本、资源投入、上一代参考）：影响方向和幅度可调，体现为较宽的把握区间（±8%）。
  • 硬性约束（供应计划 / 渠道可售库存）：先按考量得到市场口径预测，再按可售库存向下修正，修正段把握大（±2%）。界面上不出现这对术语，只用「把握大 / 把握中」与区间宽窄表达。
  • 销量与单台毛利加权汇总为销毛；价格链（成本+竞品 9 项考量 → 价格 → 毛利）与销量链在销毛处汇合。

2 · 界面一：量价走势（结论看板）

定位：给决策者的「事实+结论」页——图给证据、右侧结论栏给判断；不再需要任何预测。与现有一线操作底座并存（底座不动，本页可从底座一键切换，筛选口径共享）。

看板图形态结论栏示例（类型）
① 大盘大盘销量指数线（基线 100）+ 同比小柱（vs 2025 同周） + 事件锚点（编号锚点+图下名录）+ 结论栏内嵌领跌拆解（品牌贡献条 + 点击剔除验证）大盘同比 −4.1% 连续走低（数据）；点「小米」剔除后 −2.2% vs 全大盘 −4.1% → 小米在领跌（交互结论）
② 品牌与 Top 品
新增		左：品牌份额走势（月，品牌色）；右：各品牌 Top 品清单（传播名 · 周销 · 份额 · 4 周趋势）三星 28% 居首 +4.2pt（数据）；小米 Note 17 未接棒、Top 品仍是 Note 15——两代同跑实证（数据）
③ 价格 · 策略与影响左：品牌均价走势（品牌色，主品最粗）；右：份额变化横条（升蓝降红）Galaxy S26 连续 12 周 $799 低位不动，Xiaomi/Honor 累计 +7~11%（数据）；Honor 涨价后周销 −18%（分析）
④ 量价主品周销柱 + 价格线（双轴）+ 参考线（上一代上市同期）+ 降价/竞品锚点W42 降价 $50 → 周销 +23%（数据）；爬坡斜率高于上一代同期 +18%（分析）
⑤ 库存渠道库存柱 + 渠道 DOS 线 + 全流程 DOS 虚线 + SI ▼ 供应时点 + DNS 钻取点DOS 健康带内（数据）；上一代收尾期库存降但 DOS 升 = 周销降更快所致，勿读作备货充足（分析）
⑥ 成本销毛月版本成本阶梯线 + 周销毛琥珀柱（柱+折线）+ 价格线10 月成本版本 −2.3%（数据）；降价对冲后周销毛 978→1,079 万美元（分析）
  • 时间选择器默认最近 8 周，可拖动起点回看历史（窗口左移）；本页不出现任何预测元素。
  • 结论栏每条带类型标（数据/资讯/分析）；「分析」类结论必须能在本卡图上找到证据点，否则不写。

3 · 界面二：量价预测（推演看板）

定位：视觉重心是主品的量价预测主图（历史实线实柱 + 未来虚线虚柱 + 参考线 + 把握区间）；下方因子区是「上面为什么会这样走」的来源与操作面。预测窗口固定向未来 8 周（1–2 个月，对齐精度要求）。

主图规格

  • 销量柱：历史浅蓝实心；预测白底蓝描边虚柱；按可售库存修正段（W50 起）描边转琥珀；柱顶画把握区间帽（窄=把握大）。
  • 不含库存限制的细虚线与主柱的分叉段淡琥珀着色 = 约束缺口；缺口合计进摘要条。
  • 价格线右轴（实→虚）；参考线「上一代上市同期」灰虚线按周龄对齐；今天分界线；黑五档期背景带；事件编号锚点+图下名录。
  • 悬停：十字线 + 周读数；预测周追加「本周考量」构成（各来源影响幅度条）；点击预测柱 → 微调。

因子区（来源 + 操作）

  • 大盘 · 需求与档期（全宽）：大盘指数小图 + 增幅拖板（−20%~+30%，同比口径）+ 资源投入三档与备注（额外变量并入口袋） + 事件列表（大促/竞品/大事件三类，开关+幅度）+「添加事件」（历史对标推荐弹窗）。
  • 库存 · 供应修正（左半）：库存柱（历史实/计划虚）+ DOS 线 + SI 计划 ▼ + 输出结论「W50 起按可售修正 −16%~−33%」+ 把握大 ±2%。
  • 成本与销毛（右半）：成本阶梯 + 预测销毛柱 + 输出「全窗口销毛」+ 把握中 ±8%。
  • 竞品对标（左半）：两代同跑判定（过阈值自动切换对标代次）+ 历史对标套用记录 + 弹窗入口。
  • 自家挤占（右半）新增：两款档位重叠的自家品对照（手机 / 穿戴双场景切换）+ 挤占读数 + 承接修正开关（联动主图 W45–W48 +2%）+ 把握低 ±12%（最难量化，区间最宽）。

推演纪要

  • 每次操作自动留痕：时间 / 类型（生成 · 考量调整 · 事件 · 手调）/ 操作人 / 内容 / 原因。
  • 手调强制写原因：微调浮层中原因未填写时「应用并记录」禁用。
  • 「生成本期预测纪要」输出会议结论（图 + 考量 + 调整记录一张图）。

4 · 口径与证据规则

  • DOS（天）= 渠道库存 ÷ 近 4 周平均周销 × 7（手机按 90 天档管理，下限 21 天）；全流程 DOS 另含机关已产出未发货部分。
  • 成本按月版本阶梯，预测段沿用版本趋势；销毛（万美元）= 周销（万台）× [价格（USD）− 当期成本（USD）]；换算百万美元时再 ÷ 100。
  • 两代同跑切换阈值 70%：新代周销达旧代同期 70% 前，价格对标以旧代为准。
  • 结论三类型：数据（图上可证）/ 资讯（确定性公开信息）/ 分析（推断，须给证据点）。相关关系不写成确定因果。
  • 预测期锚定「今天」向右 8 周；历史段永不改写，手调只落在预测段。Mate 80 的未来段参考线同样是已发生历史按同周龄映射，不是未来实际。
  • 数据状态：本稿所有数值均为演示，走势页标「演示 · 混合数据」，预测页标「演示 · 模拟预测」；把握区间是模型假设，不宣称校准后的统计置信区间。

5 · 视觉遵循（既有系统）

  • tokens：ink #171717 / mute #737373 / hairline #ebebeb / 单蓝 #0070f3 / 浅蓝选中 #e8f1ff·#0053c2 / 琥珀限量（大促·约束·手调）/ 语义红（下调）。品牌线色沿用 brandColor（主品红最粗）。
  • 实际=实线实柱、预测=虚线虚柱（沿用滚动预测稿语言）；编号锚点+图下名录；图上只留数据与控件，结论下沉结论栏；全站无「我司」字样；卡片无左色线。

6 · 关键交互与状态契约

用户动作即时反馈留痕、确认与边界
走势页拖动历史窗口大盘与量价图同步换窗，范围文字同步为 W 起–W 止 / 周数只改变查看范围，不改模型历史；不出现未来数据
点击品牌剔除验证选中行、剔除后同比和判断文案同步更新判断是当前口径下的方向性读数；可换品牌继续对照，不写成业务因果证明
调整预测因子 / 事件主图、库存修正、摘要、成本销毛与逐周数据表同源重算修改仅进入本地草稿；change 后写纪要；「撤销上一调整」回到上一考量快照
添加竞品事件原生弹窗展示推荐历史交叉关系；可改选参考、幅度和周期取消不应用；应用后才联动主图，并同步实际影响周与参考来源
点击预测柱 / 键盘 Enter打开该周微调弹窗，展示当前值、调整后值与原因原因为空时保存禁用；手调标记、数据表状态、纪要和 tooltip 原因一致
另存情景保存当前考量快照并新增保存记录原型仅写本机 localStorage，不写业务系统；正式实现仍需确认、版本与撤销
生成预测纪要下载独立 HTML，含当前摘要、考量、库存修正周与调整原因导出内容显式标注演示边界，可直接归档或投屏复盘

7 · 响应式、可访问性与异常状态

  • 桌面优先；≤1100px 结论栏下移、双卡改单栏；≤680px 筛选与摘要单列，图表只在自身容器横向滚动，不裁切关键数值。
  • 三个主视图使用 tab 语义与左右方向键；所有按钮有可见 focus；开关暴露 checked 状态；滑杆保留原生键盘行为与 aria-valuetext。
  • 竞品对标与单周微调使用原生 dialog，支持焦点约束、Esc 关闭与焦点返回；主图预测柱支持 Enter / Space。
  • 主图提供逐周数据表；其他图表有相邻文字摘要。真实、演示、混合状态用文字 badge，不依赖颜色单独传达。
  • 库存未触发时不显示固定 W50 标记，摘要显示「未触发」；预测极值自适应 Y 轴；缺数保持 —，不插值、不造点。
  • prefers-reduced-motion 下取消过渡动画但保留即时状态反馈；本原型无后端请求，加载 / 请求失败 / 权限失败不属于可演示状态。
