## 完成了什么

**南非市场深化**
- 先付/后付两级付费口径上线：运营商小册子数据按「付费方式＋后付期数（24/36/48 期）」两级筛选，48 期数据纳入运行时（此前直接丢弃）；此前南非「没数据」的根因（默认口径为空）一并根治。
- 规格未标明问题根治：册子规格列参与产品匹配，「规格未标明」行数 1599→766，典型机型挂上真实容量 SKU；明细表新增平台成交价、分期价与促销政策字段，产品标签自动携带分期标注；切换期数不再清空已选产品。
- 数据整备轮：采集记录标识碰撞消歧（213 组→0）、册子映射优先级合并与空规格诚实降级、汇率倒挂中位数自校验、同秒多次采集取最低价；人工裁定独立于数据守卫总开关（关闭守卫不影响已裁定结果）。

**竞品配对规则重写（五图拍板）**
- 平板配对规则重写：先按屏幕尺寸分桶、桶内「便宜对便宜」一一对应；友商更多时认领同容量全部变体、自有更多时友商就近复用——对标关系贴近真实竞逐格局。
- 数据纠偏：幻影规格笔误删除并回真实档、僵尸型号折叠回真身（各默认块国家对标复活，对标数据＋81 行）；默认块个别竞品按拍板调整（平板与穿戴两处）。

**真实销量（PSI）接口预留与数据分发形态升级**
- PSI 接口预留（对接采集团队的关键一步）：四产业配置维度口径落全链（穿戴表盘升为配置维度、多尺寸型号拆分），销量数据三级管线（采集行原样承载→归一化清洗→真实销量优先、无采集回落估算）；量带悬停动态标注「真实销量 / 估算口径」，配置页新增销量诊断；样例数据包生成器（近 7 万行×605 型号×25 国）与契约文档入库，为真实数据接入提供验收基准。
- 分发形态升级：数据包导入/导出/还原内置（导入前校验防半写入），便携版一键打包（单文件应用＋数据包＋使用说明）支持带完整数据的离线交付；数据包 v3 转为「原表模式」——内部系统只倒原表，派生内容应用内构建，规则类内容全部配置表维护；新增按国家子集生成数据包的配套工具（已实测九国包导入验证）。
- 业务规则零内置（11-18 指令）：系列规则、分档阶梯、型号别名等 133 条规则数据全部移出应用代码，配置表成为唯一规则源——规则调整不再依赖发版。

**预警中心真实使用化（三指令＋拍板轮，共十项）**
- 处理收件箱整卡退役（批量处理/全选/生命周期筛选芯片下线，处理生命周期保留 Agent 深链通道）；每产品新增独立规则开关（调价/折扣/平台价差/档位间距四类，改即生效、恢复即跟随全局）。
- 添加监控换为与看板完全一致的四列产品树浮窗（搜索、档位、排序同款，天然排除无数据产品）；铃铛订阅改删除＋二次确认。
- 拍板轮八项：Agent 预警深链即时生效、竞品行诚实标注、档位间距徽标只亮涉事档位、脏订阅显式提示不再静默、概览带点击切换只看异常、添加监控主按钮化、齿轮弹层快捷覆写阈值等。

**看板呈现多轮审核定版**
- 平台筛选器重写为「平台→渠道→卖家」三列级联并三轮定版：平台名单击只切换不展开、行尾下钻按钮手动展开、浮层宽随内容自适应、自动/钉定店铺两种打开行为。
- 量价归属与名称带：归属药丸两行定稿＋候选菜单水平弹出、销量层恒为柱形、自动取价口径改为默认锚严格取价（每周恒定默认主店，不再逐周漂移）——取价基准稳定可预期；稀疏孤点保留落点与标签、周标签只写周号跨年才带年份、明细金额去货币符号、「取证」行更名「记录」；配置页显示构建时间（辅助定位多机版本差异）。
- 悬停卡定位四轮打磨定稿：恒卡十字右上、像素级校准、右缘翻转贴十字、分图模式不再被容器裁切；销毛率迷你卡恢复且数值改「xx.x%」占位——推算口径显性化，不误读为事实。

**Agent 与体验收尾**
- Agent 会话与全局搜索统一接入成熟组件基座，界面标准化、后续对话能力迭代有统一定制点；多平台对比进入稳定版通道（对外演示与内部迭代同享）；价格走势 Y 轴自动压缩默认关闭，默认视图呈现真实价格比例。
- 体验修复：看板产品树「点了又立刻退出」根治（关闭须真实外部按下背书）、时间面板连续改选卡死修复、预警添加监控浮窗误关两连修、语音输入全链下线；页面快照恢复模拟占位图（无真实取证时展示示例图，琥珀提示＋「模拟」徽标显性标注，真实证据优先原则不变）。
- 全量审计修复轮（11-18）：5 项 P1＋16 项 P2 全数修复，自动化测试增至 2088 项全绿。
