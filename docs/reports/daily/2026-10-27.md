# PriceLens 开发日报 · 2026-10-27（周二）

## 完成了什么

**数据源治理（归并定案落地 + 清洗版接入）**
- 平台归并定案落地：业务确认 MVM 与 M.Video 为同一平台，统一命名「Mvideo」，数据管线全量重跑，参考价与预警阈值随之校准（第 158 轮）。
- 源数据表清洗版交付并接入系统：五组平台名归并（M.Video/MVM、Amazon 各国变体、MediaMarkt TR、Mercado Libre、Vatan）、店铺名称规范化（约 1.4 万行显示名与 8300 行店铺名归一）、官网模拟价列整体退役——系统取价基准改用平台真实划线价，价格口径更贴近电商实际（第 159、160 轮）。

**渠道口径精细化（每条产品线独立选渠道）**
- 每条产品线可单独选择平台与店铺，缺省自动选最优渠道；主品与对比品渠道互不牵连，原全局「平台/店铺」筛选在看板与量价页退役（总览与预警保留全局口径），比价视角更贴近单品实操（第 160 轮）。
- 渠道选择入口移入产品筛选器：每条产品线在颜色旁直接出渠道标签；渠道浮层重写为「平台 → 渠道 → 卖家」三级级联，与全局平台筛选同一套交互语言（第 161 轮）。
- 「自动」语义升级为每周动态：自动模式下每条产品线每周显示全部平台-店铺中的最低价（哪家最低显示哪家），取证来源随行记录——自动口径从「锁定单一渠道」升级为「逐周跟踪市场竞争」（第 162 轮）。
- 图例区改版：产品药丸上方独立显示平台小药丸（自动模式同样显示当周实际取数平台名），多平台比价入口移至同行居右、常驻显示；明细表每产品新增「平台-店铺」来源行，「权益」列更名为「offer」（第 162、163 轮）。

质量口径：六轮迭代通过全量自动化测试（338 项单测）与真机走查；数据管线三步全量重跑、金测锚全数校准。
