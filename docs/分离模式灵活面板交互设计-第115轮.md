# 分离模式灵活面板交互设计（第 115 轮第 10 条 · 设计稿待拍板）

> 2026-10-21 · 背景：当前分离模式默认「每张面板 = 一款我司配置 + 它的对标竞品」，隐含两个假设——默认竞品配置是对的、用户一定选了我司产品。**当竞品配错、或用户就想对比 Apple vs Samsung（竞品对竞品）时，没有把产品自由分配到面板的通路。** 本稿给出交互设计，未实现，待拍板后施工。

## 一、设计目标

1. 分离模式下，用户可以把**任意已选产品（我司或竞品）自由指定到任意面板**；
2. 不破坏现有默认：自动模式下面板仍按「我司配置 + 对标」自动组装；
3. 交互语言与现有筛选器/面板一致（浅蓝选中、拖拽把手已存在、无隐藏默认）；
4. 单图 ≤8 条红线在自由分配下依然成立（分配超限时即时拦截）。

## 二、方案：面板头「＋ 添加产品」+ 产品卡「移入/移出」

### 2.1 面板头入口

每张分离面板的头部（现有型号名左侧区域）新增一个 **「＋」胶囊按钮**：

```
┌─ Pura 90s Pro Max · 12+256 ──────────── [＋ 添加产品] ─┐
│  Huawei                          Apple                 │
│  ● Pura 90s Pro Max 12+256       ● iPhone 17 Pro 12+256│
│                                                         │
│  [图表]                                                 │
└─────────────────────────────────────────────────────────┘
```

- 点击「＋」弹出**产品选择浮层**（复用我司/竞品级联同款 CascadePanel，品牌 → 型号 → 配置，列宽自适应）；
- 浮层内勾选即把该配置**加入本面板**（面板 = 图上多一条线 + 图例带多一个药丸）；
- 候选范围 = 当前筛选器已选产品 ∪ 该国该产业全部产品（未选的加入时同步写入筛选器，保证「图上有的、筛选器里一定有」，明细表口径不漂）。

### 2.2 移出与改派

- 图例带药丸**长按/右键 → 「移出本面板」**；或药丸尾部 hover 出现小「×」；
- 也可直接**拖拽药丸到另一张面板**（与现有面板拖拽换位同语言：拖把手 = 换面板位置，拖药丸 = 移动产品归属）；
- 我司产品被移出且面板为空 → 面板自动收起（沿用「不足 2 面板自动关」逻辑）。

### 2.3 分配状态与「自动」

- 任何手动分配动作 = 退出「自动组装」，面板头出现淡蓝「手动布局」标记 + **「恢复自动」**链接（一键回到按对标矩阵组装，与 BenchConfigModal「恢复默认 auto」同语言）；
- 手动布局不写死国家/产业：切换国家后自动回到自动组装（避免跨国的无效手工映射）。

### 2.4 红线约束（≤8 条/图）

- 添加第 8 条后「＋」浮层内其余产品置灰，提示「单图最多 8 条产品线」；
- 拖拽落点面板已满 8 条 → 落点面板描红抖动 + toast 拦截。

### 2.5 典型场景走查

| 场景 | 操作 |
|------|------|
| 竞品配错了，想换 | 面板图例带上右键该竞品 → 移出；「＋」里选正确的 |
| 只想看 Apple vs Samsung | 筛选器不选我司（竞品视角）；面板 1「＋」加 iPhone 17 Pro，面板 2「＋」加 S26 Ultra；或合并进一张面板对比 |
| 我司两款打一款竞品 | 面板 1 默认（Pura 90s PM + 对标）；面板 2「＋」手动加 Pura 90s Pro + S26 Ultra |
| 想对比苹果和三星（多面板） | 每张面板放一个品牌的一款产品，X 轴共享、跨面板参考线已支持 |

## 三、实现要点（施工预估）

- 状态：`panelAssign: Record<panelKey, seriesKey[]>`（localStorage 持久化，键随国家/产业重置）；
- `panels` 组装逻辑改为「有手动分配读分配，无则走现有 mappedComps」；
- 图例带（本轮已上）天然支持面板内任意产品集合，无需改 Chart；
- 拖拽药丸 = HTML5 drag（面板卡已有的 dragover/drop 事件上区分 dataTransfer 类型）；
- 预估 1 轮施工 + 1 轮评审打磨。

## 四、待拍板

1. 「＋」浮层候选是否允许**未在筛选器选中的产品**（本稿：允许，加入时同步写入筛选器）？
2. 手动布局是否需要**跨会话记忆**（本稿：记 localStorage，切国家即重置）？
3. 竞品对竞品视角（无我司）时，「恢复自动」按钮是否有意义（此时无对标锚点，建议隐藏该按钮）？
4. 是否需要「每面板也限我司产品数」（如每面板最多 2 款我司，避免单图变全品类大杂烩）？
