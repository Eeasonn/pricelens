## 1. 背景与问题

「价格走势」页顶部产品药丸的隐藏/显示很自然，因为**一个产品 = 一条线**：点击药丸，线消失、
Y 轴收缩、药丸变虚线置灰态，点击恢复。

「量价」页的产品单元不是线，而是**一整个面板**（价格线 + 销量柱 + 成本销毛带 + 双极差卡 +
单周明细卡 + 独立时间轴），面板数由顶部「选择产品」筛选器决定（阅读视图 = 各卡主品；
组内对比 = 一卡的主品 + 其对比品）。照搬「隐藏」有三个语义难题：

1. **隐藏的宾语是什么**：一条线消失后图还在；一个面板消失后是一整块视觉区域的去留，不能「只是线没了」。
2. **布局耦合**：面板按 ≤3 均分一行、>3 横向拖动排布（`VolumePrice.tsx` 面板 grid），移除任何面板都会改变其余面板的宽度与位置。
3. **伴随件与联动**：面板自带极差卡/明细卡/时间轴；共享 Y 轴列、同步时间轴、悬停联动建立在「面板在场」上。

用户诉求的本质：在量价页**快速减少同时观察的产品数、临时聚焦、且容易恢复**——与价格页药丸同一心智。

## 2. 现状盘点

### 2.1 两页药丸行为对照（实现基线）

| 维度 | 价格走势（`BrandLegendStrip.tsx` + `PriceTrend/index.tsx`） | 量价（`VolumePrice.tsx`） |
|---|---|---|
| 药丸形态 | 两行药丸（品牌行 + 名称行 + 配置 chip），圆角矩形 10px；191 轮起与量价共用 `PillUnit` | 组内对比同款 `PillUnit`；**阅读视图是纯文本头**（非按钮） |
| 点击语义 | 隐藏/恢复该系列折线 | 组内对比：切换 `hiddenPanelKeys`（8ac3df6 引入）；阅读视图：不可点 |
| 隐藏态视觉 | 虚线 hairlineStrong 描边 + opacity .45，title「点击恢复显示该产品」 | 药丸同款虚线态；**但面板保留原位、图表清空**，图区显示「已隐藏，点击产品名恢复显示」 |
| Y 轴跟随 | `chartSeries` 过滤 + `yAdaptKey` 含 hiddenKeys，**刻度随可见系列收缩** | `visUnion`（共享 Y 轴并集）与 `adaptiveSeries`（时间自适应）**均不过滤被隐藏面板**——刻度不收缩 |
| 主品可隐藏 | 可以（主品线同规则） | 组内对比可以（现状） |
| 全局快捷 | 工具行「隐藏对比产品」（跨组批量） | 无 |
| 状态 | `useState` 瞬态；换产品/价格类型/币种复位；不进 URL、不进会话 | `useState` 瞬态；仅组内对比生效 |
| 悬停联动 | 药丸 hover = 高亮该系列、其余降透明 | 无（量价每面板单系列，无此需求，onHover 传 no-op） |

### 2.2 现状初版的三个问题（本设计要替换的对象）

组内对比现有的「隐藏 = 面板保留、图表清空」（`VolumePrice.tsx:931` `panelHidden`）是半隐藏态：

1. **只覆盖组内对比**：阅读视图（主产品面板）完全没有该能力，而阅读视图往往是面板最多的场景。
2. **占位不干活**：被隐藏面板仍占满一个网格位，留下一大块只有提示文字的白空间；「少看几个」的空间收益为零，这正是「不自然」的来源。
3. **刻度不跟随**：共享 Y 轴与时间自适应范围仍把被隐藏面板的数据算进并集（`visUnion` 取全部 `panelViews`），隐藏后轴刻度不变，违背价格页「Y 轴自适应随可见系列收缩」的既有口径。

## 3. 设计判断基线

- **药丸语言一致性**：191 轮已把两页药丸*显示*统一（`PillUnit` 导出复用）；显隐*行为*也应同构——点击隐藏、虚线置灰、点击恢复、title/aria-pressed 同文案。不发明第二种「隐藏」视觉语言。
- **状态不靠颜色单独传达**：虚线态 + title + aria-pressed 三重表达（DESIGN.md Do's）。
- **筛选条答「看什么数据」，图表控件答「怎么看」**：本能力是**页内临时显隐**，不得写回筛选器/URL（用户在量价页隐藏产品 ≠ 从选择产品浮窗移除产品），暂存条文案与行为要让这一点自明。
- **动效三档**：反馈 160ms / 模式切换 240ms；`prefers-reduced-motion` 保留状态变化、移除位移。
- **键盘**：药丸是原生 button（现状已是）；隐藏后面板卸载，焦点必须有人接（187 轮键盘审计精神）。

## 4. 三个候选方案

### 方案 A：移除式隐藏 + 暂存条（推荐）

**交互说明**

1. **入口统一**：两种视图的面板头药丸都可点击。组内对比维持现状 `PillUnit` 点击；阅读视图的面板头从纯文本升级为可点击药丸（信息结构不变：平台行 + 品牌行 + 名称行 + 配置 chip，右侧「本组对比（N）」入口保留）。
2. **点击药丸 = 隐藏**：该面板整体移出网格（极差卡/明细卡/成本带/时间轴随面板一起消失——它们是面板的组成部分）；剩余面板立即重排，grid 列数 = 可见面板数（≤3 均分一行，>3 保持横滚、轨道宽按可见数重算）。
3. **暂存条（量价页的「药丸带」）**：面板区下方出现一条常驻收纳条——「已隐藏（N）：」+ 每个被隐藏产品的**单行迷你药丸**（品牌色点 + 名称 + 配置，虚线 hairlineStrong 描边，同价格页小 pill 隐藏态语言）+「全部恢复」。点击迷你药丸 = 该产品恢复到原有位置（拖拽换位序 `panelOrder` 优先、缺省数据序）。无隐藏时暂存条不渲染。
4. **刻度跟随**：共享 Y 轴并集（`visUnion`）与时间自适应范围（`adaptiveSeries`）只按**可见面板**计算——高价竞品隐藏后轴收缩，这是本方案在量价页独有的价值（价格页隐藏线收缩 Y 轴的同款口径）。
5. **全隐藏空态**：允许隐藏到零。面板区显示虚线框空态「已隐藏全部产品」+ 居中「全部恢复」按钮；暂存条此时不再重复渲染。与价格页「全隐藏 = 图空 + 药丸带还在」心智一致，无死锁。
6. **复位时机（与价格页对齐）**：产品清单/价格类型/币种变化 → 清空隐藏集（挂进现有 `scaleResetKey` 复位效果）；粒度、国家切换不清（产品 key `modelId__romram` 不随其变化）。
7. **状态档位**：会话态 `usePageViewState('volume.hiddenPanels')`——切价格页再回来保留；刷新/新开页签回默认；**不进 URL**（理由见 §5.6）。切换视图模式（阅读 ↔ 组内对比）清空：两视图面板集不同，「一次看一组」的心智下从空集开始最稳。

**低保真示意**：demo 页「方案 A」标签页——点击任一面板头药丸体验隐藏/重排/暂存条/恢复/全隐藏空态。

**优点**

- 与价格页药丸行为**完全同构**（点击隐藏、虚线可恢复、Y 轴收缩、主品同规则），零学习成本——直接回应「价格走势很自然」的提问出发点。
- **空间收益真实**：量价面板是全套件重内容（主图 + 成本带 + 双极差卡 + 明细卡 + 时间轴，纵向 ~400px），收起后其余面板变宽，直接缓解三面板并排时极差卡 148px 最小可读宽度的压力。
- 解决共享 Y 轴被高价产品拉爆的真实痛点。
- 实现路径最稳：见 §7「渲染层过滤」——不需要面板态数组改 key 制，绕开 2026-11-01 审查 P2-6 那类下标错位坑。

**缺点 / 风险与缓解**

- 重排引起布局位移（面板变宽、>3 横滚时滚动内容左移）。缓解：240ms 布局过渡；reduced-motion 直跳；浏览器 scroll anchoring 兜底。
- 「面板去哪了」的可发现性依赖暂存条。缓解：暂存条紧贴面板区（同一卡片内、时间轴行下方），出现时 160ms fade + 「已隐藏（N）」文字标签明示数量；药丸 title 一贯写明「点击隐藏该产品」。
- 误读风险：用户以为产品被从筛选器移除。缓解：暂存条就在面板区内、恢复一键完成，行为自解释；不写任何工程味文案。

**实现成本**：中低（约 0.5–1 天含双视口实测）。改动集中在 `VolumePrice.tsx`：阅读视图面板头按钮化、隐藏集状态、渲染层过滤、暂存条小组件、空态、焦点承接、复位挂载；无新 token、无数据层改动。

### 方案 B：原位折叠成摘要行

**交互说明**

点击药丸 = 该面板**在原列位**收成一行 ~48px 摘要条：虚线态药丸 + 区间读数（价格 Δ / 销量 Δ，取当前查看窗口口径）+「展开面板」按钮；位置与宽度不变，其余面板不受影响。点击摘要条任意处恢复。Y 轴并集同样只算未折叠面板。

**低保真示意**：demo 页「方案 B」标签页。

**优点**

- 无重排跳动，位置恒定，「它在原地只是收起来了」心智简单。
- 摘要行保留信息香味（关键 Δ 读数可见），比完全消失克制。
- 面板态数组下标稳定，不触发错位类问题。

**缺点**

- **横向空间零释放**：折叠面板仍占满一个网格列位（只是变矮），「少看几个、看大图」的诉求只完成一半；>3 横滚时折叠面板继续占宽，与现状「占位白图」的差别仅是高度。
- 与价格页「隐藏 = 消失」语义**形似实异**：药丸虚线态相同，但一个消失一个变矮，两页行为不一致。
- 摘要读数口径是新增设计债：取查看窗口还是拖选区间？被折叠面板的 brush 还算数吗？（需另定「折叠即清 brush、摘要行用查看窗口口径」之类规则。）
- 网格内出现「一行扁条 + 两列满高面板」的混合高度布局，视觉节奏差，实现（grid 行为 + 高度过渡）反而更琐碎。

**实现成本**：中高（折叠组件 + 摘要读数管线 + 混合布局）。**风险**：摘要口径争议 + 一致性折扣。

### 方案 C：聚焦 solo

**交互说明**

不做任意隐藏，改「聚焦」：点击药丸 = 本页只保留该产品面板（满宽独占），其余产品收进暂存条；再次点击（或「显示全部」）恢复全部。状态只有一个 solo key。

**低保真示意**：demo 页「方案 C」标签页。

**优点**

- 语义直白、状态最简，无组合爆炸。
- 单产品满宽阅读体验好（量价面板全套件在 1/3 列宽下确实挤）。

**缺点**

- **不能任意组合**：想同看 A+B 不看 C/D 做不到——而这正是「隐藏」的真需求（价格页药丸就是任意组合）。
- solo 后跨面板联动（同步时间轴、悬停同列、共享 Y 轴对照）整体退化为单面板，量价页「多产品对照」的核心价值在 solo 常态下失效。
- 与价格页心智不一致。

**实现成本**：低。**定位**：不推荐单独落地；可作为方案 A 之后的轻量增强（A 的暂存条天然支持「只留一个」= 逐个隐藏其余，覆盖了 solo 的主场景，无需单独机制）。

### 4.4 三方案对照表

| 维度 | A 移除 + 暂存条 | B 原位折叠摘要 | C 聚焦 solo |

## 5. 横切议题逐项裁定

### 5.1 主产品能否隐藏、至少保留几个

**主产品可隐藏，允许全部隐藏（空态兜底），不设「至少保留 1」守卫。** 理由：

- 量价面板是独立单元，主品面板没有锚定全局的职责——共享 Y 轴列、同步时间轴、暂存条都是页面级组件，不挂在任何面板上；主品隐藏不影响全局件。
- 价格页主品线本就可隐藏（现状），一致。
- 「至少 1」守卫需要在最后一颗药丸上做禁用 + 提示，增加一条特殊规则；空态（含全部恢复）已是无死锁的兜底，规则更少。
- 两个次生影响，均可接受：①组内对比主品隐藏后其「店铺同步」按钮随面板卸载，同步状态按卡保留、恢复后原样回来；②阅读视图主品隐藏后其「本组对比（N）」入口暂不可达，恢复即可——空态永远提供出口。

### 5.2 与价格走势 pill 的视觉 / 行为一致性

| 一致项 | 约定 |
|---|---|
| 点击语义 | 点击药丸 = 隐藏；再点（恢复入口）= 显示 |
| 隐藏态视觉 | 虚线 hairlineStrong 描边 + 降透明，title「点击恢复显示该产品」 |
| 可访问性 | 原生 button + `aria-pressed` + title，与 `BrandLegendStrip.Pill` 同款 |
| Y 轴跟随 | 隐藏即退出并集，刻度收缩（价格页 `yAdaptKey` 含 hiddenKeys 的同口径） |
| 主品规则 | 可隐藏 |
| 复位时机 | 产品清单/价格类型/币种变化清空 |

两处**有意不一致**（量价结构决定的）：①价格页被隐藏系列的药丸留在原药丸带原位（带不动），量价被隐藏面板的药丸随面板消失、由暂存条承载恢复——暂存条在交互角色上等价于价格页的药丸带；②量价无药丸 hover 高亮联动（每面板单系列，无对象可联动），维持现状 no-op。

### 5.3 同步时间轴、悬停联动、极差卡 / 单周明细卡如何跟随

方案 A 下的裁定（按「渲染层过滤」实现方式自然成立，见 §7）：

- **面板级组件**（极差卡、单周明细卡、成本销毛带、独立时间轴、店铺同步按钮）：随面板整体消失/恢复，无独立处理。
- **共享 Y 轴列**：`visUnion` 只聚合可见面板；档位值 `tierValues` 同步随可见集。
- **时间自适应范围**：`adaptiveSeries` 只算可见面板——被高价长周期竞品拉宽的查看范围随隐藏收缩。
- **同步时间轴**：共享窗口（`win`）是页面级状态，不因隐藏变化；可见面板拖任一时间轴照旧联动。非同步独立窗口 `panelWins` 按面板（全量下标）保留，隐藏面板的独立窗口留着，恢复后回到原窗口。
- **悬停联动 / 观察列**：同步模式悬停列写全部面板（含隐藏，数组层面），隐藏面板不渲染即无视觉；恢复后联动无缝继续。
- **拖选区间 brush**：同上，按面板保留。同步模式下 brush 联动写全量数组，隐藏面板恢复后 brush 与其余面板一致。
- **拖拽换位 `panelOrder`**：按 key 记录，隐藏面板的位置序保留，恢复插回原位。

一句话：**所有页面级联动只看可见面板，所有面板级状态按面板保留**——过滤发生在渲染层，状态层不动。

### 5.4 390px 移动端

- 暂存条：迷你药丸 `flex-wrap` 换行（每行 ~2 颗），「全部恢复」按钮恒可见不掉行；条自身不入横滚区（面板区 `lpl-card-scroll` 之外、卡内底部）。
- 面板区：维持既有 `minWidth 880` 局部横滚；隐藏后可见数变少、grid 重算，窄屏收益与桌面同向。
- 空态：短文案「已隐藏全部产品」+ 按钮，390px 无溢出（demo 已按 390 冒烟）。
- 触控：药丸命中区即两行药丸本体（≥44px 高），恢复迷你药丸高 ~26px 配 `lpl-hit` 外扩命中区（既有类）。

### 5.5 键盘与无障碍

- 药丸/迷你药丸均为原生 `button`；`aria-pressed` 表隐藏态；title 与 `aria-label` 用业务文案（「恢复显示 Pura 80 Pro」），禁工程语。
- **焦点承接（关键细节）**：点击药丸隐藏后，该药丸随面板卸载，焦点必须移到暂存条中对应的迷你药丸上（键盘用户 Tab 流不断、操作可连续撤销）；「全部恢复」后焦点落到第一个恢复面板的药丸；迷你药丸点击恢复后焦点回该面板头药丸。实现为渲染后的 ref 定位（demo 已示意该行为）。
- 暂存条 `role="group"` + `aria-label="已隐藏产品，N 个"`。
- 空态按钮可达即可，无需 aria-live（焦点不落在空态场景时由 Tab 自然到达）。
- 无新键盘快捷键（克制；面板图内 ←/→ 观察列键盘行为不变）。

### 5.6 状态是否进 URL / 记忆

**会话态（`usePageViewState`），不进 URL、不落盘。**

- 与量价页既有视图态同档（`synced`/`labelMode`/`windowIds` 均会话态）：隐藏组合是用户精心调整的分析语境，切价格页再回来应保留；刷新/新开页签回到默认。
- **不进 URL**：URL 现承载全局筛选（国家、平台等分享语义）；页内临时显隐进 URL 会污染分享口径——隐藏是「本页怎么看」，不是「看什么数据」。
- 与价格页的差异（价格页 `hiddenKeys` 是瞬态 `useState`，切页即失）：量价做成会话态略优于价格页；两页统一升级留作后续小项（§8 待拍板 5），不阻塞本设计。
- 切换阅读视图 ↔ 组内对比时清空隐藏集（两视图面板集不同，从空集开始）。

### 5.7 与其他入口的关系

- **不引入**价格页的「隐藏对比产品」全局按钮：量价组内对比面板数少（主品 + 对比品），逐个点药丸足够；暂存条「全部恢复」已覆盖批量场景。
- **不改**「选择产品」筛选器：页内隐藏与数据范围严格分离（§3 基线）。
- **不动**面板拖拽换位：隐藏与换位正交，`panelOrder` 照旧。

## 6. 推荐方案与理由

**推荐方案 A（移除式隐藏 + 暂存条）。**

1. **一致性是第一理由**：用户提问的出发点就是「价格走势很自然」；A 是唯一与价格页药丸行为完全同构的方案（点击隐藏、虚线可恢复、Y 轴收缩、主品同规则），191 轮统一了两页药丸的显示，A 把行为也统一。
2. **量价页专属价值**：面板全套件重内容 + 共享 Y 轴，隐藏真实释放横向空间、收缩被拉爆的刻度——这两个收益在价格页（少一条线）远小于量价页（少一套面板）。
3. **实现最稳**：渲染层过滤（§7）绕开面板态数组下标错位这一已两次咬人的坑（审查 P2-6），无需 key 制重构；B 的混合布局与摘要读数反而是新的不确定面。
4. **B 的优势不足以翻盘**：B 唯一实质优势是「无重排位移」，代价是横向零释放 + 一致性折扣 + 摘要口径债；240ms 过渡 + scroll anchoring 已把 A 的位移代价压到可接受。C 的 solo 场景被 A 的「逐个隐藏其余 + 全部恢复」天然覆盖。

## 7. 实现提示（供后续施工会话，本轮不实现）

- **渲染层过滤（核心手法）**：`panelSpecs`/`panelData`/`panelViews` 保持全量（数据层与全部按下标挂的面板态数组——`hoverIdxs`/`geoms`/`brushes`/`brushLive`/`volumeLimits`/`panelWins`——都不动，天然避免下标错位）；只在 `orderedPanels` 之后、渲染前按 `hiddenPanels` 过滤，grid 列数与轨道宽按**可见数**重算。
- **刻度过滤**：`visUnion` 与 `adaptiveSeries` 改为只聚合可见面板（当前实现含被隐藏面板，属现状不一致，随本设计一并修）。
- **状态**：`usePageViewState<string[]>('volume.hiddenPanels', () => [])`（Set 不便序列化，存数组）；视图模式切换与 `scaleResetKey` 复位时机顺带清空。
- **阅读视图面板头按钮化**：复用 `pillOf` + `PillUnit`，保留右侧「本组对比（N）」；纯文本头退役。
- **暂存条**：新小组件（建议 `volume/HiddenTray.tsx`），迷你药丸单行虚线态，复用现有 token（无新 token）。
- **焦点承接**：渲染 effect 中按「刚发生隐藏/恢复的面板 key」定位目标按钮 focus。
- **替换现状**：组内对比现行「面板保留 + 图表清空 + emptyHint」语义整体移除（`panelHidden` 分支、`hiddenPanelKeys` 本地态）。
- **验证**：`design:check`/`design:lint`/`typecheck`/`check` + 双视口（1440/390）实测：隐藏/恢复/全隐藏空态/焦点承接/同步联动/非同步独立窗口保留/>3 横滚重排。
