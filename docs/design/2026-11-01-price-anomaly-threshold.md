## 1. 背景与问题

折后价是平台实抓在架价。爬虫会抓到**相对形态的脏点**：商品页临时挂错 variant（ accessories 价串到整机）、
币种 / 单位错读、闪促一小时的极端价、套装拆价——这类点**绝对值不离谱**（现有 5% RRP 行级守卫拦不住），
但**相邻两周变化幅度极端**（如 −60% / +120%），一粒就能污染整条分析链：

- 价格走势图出现假尖峰，Y 轴被拉爆；
- 量价页极差卡（`rangeSpreadOf` 取区间 max/min）一粒脏点即爆表；
- 环比 / 近 4 周环比出现 ±60% 假信号；
- 预警中心「调价」规则（阈值默认 1.5%）会对脏点**报真预警**——这是今天的现实缺陷；
- 多平台对比出现假平台价差。

用户诉求：相邻观测点变化超过阈值（例 30% / 50%）→ 判定「异常价格，不可采信」。

### 与三个既有机制的辨析（不合并的理由）

| 机制 | 回答的问题 | 动作 | 位置 |
|---|---|---|---|
| 预警中心「调价」规则 | 发生了业务变化吗 | 通知人 | 预警页 + `alertSubs` 订阅 |
| 图表「价格变化提醒」滑杆 | 图上哪些点变化大 | 仅视觉标注，不影响计算 | `ChartToolbar` 视图态 |
| **本设计：异常价守卫** | **这个价格点可信吗** | **打标 + 退出计算** | **取数层口径，全站生效** |

三者共享同一个环比公式（§5.1），但目的不同：预警要「报」，滑杆要「看」，守卫要「算」。
把守卫塞进滑杆（方案 C）会退化成纯标注；塞进预警会混淆业务信号与数据质量。

## 3. 设计判断基线

- **隔离 ≠ 删除**：缺采的纪律是「不插值、不造点」（PRODUCT.md）；异常价的同族纪律是**「不吞点」**——
  原值永远在点结构里、在图上可见、在表格里可读、有取证链接，只是不参与计算。任何「完全不显示」的做法违反证据优先。
- **事实层与计算层分离**：表格 / 取证 / tooltip 是事实层，**显示原值 + 打标**；图表主线与派生数字是计算层，**走可信链**。两层都要能解释自己。
- **单一事实源**：跨页一致（brief 硬要求）只能由取数层单点保证——判定进 `buildSeries`，而不是四页各自为政。
- **状态不靠颜色单独传达**：胶囊带文字（「疑 −61%」）、tooltip 带规则与数值、表格带「疑」角标（DESIGN.md Do's）。
- **写入口径集中**：全局阈值改变所有派生数字，属「read first, calculate second, write last」的写动作——集中在配置页，带预览、留痕、撤销；图上仅开放逐点人工裁定（同样二次确认 + 留痕）。
- **自动规则只隔离「明显瞬态」**：宁可漏（打琥珀标待核对，计算照常）不可错杀真实业务变化——错误隔离会静默改数字，错误放行只是多看一眼。

## 4. 三个候选方案

### 方案 A：全局数据质量口径 + 隔离态标注（推荐）

**交互说明**

1. **配置页新增「数据质量」块**（套 `Block` 壳，排「默认平台店铺」之后）：
   - 开关「异常价格守卫」+ 档位 Segmented：`关闭 / 30% / 50% / 自定义`；自定义档展开数字输入（10–90，整数，`%` 后缀，Enter / 失焦提交，复用 `YLimitHandles.LimitInput` 的解析与步进语言）。默认 **50% 开启**（理由见 §6）。
   - 一句业务说明：「相邻两个观测点的折后价变化幅度超过阈值时，该点标记为异常价格：图上保留原值但不参与计算。真实大促与官方调价自动放行，也可在图上逐点确认。」（禁工程语，符合 UI 文案铁律。）
   - **人工裁定清单**：表列 = 产品 / 周 / 原值 / 环比 / 动作（确认真实价格 · 标记异常）/ 时间，行尾「撤销」。只记人工操作；促销带与 RRP 同步的自动放行不进清单（其证据——促销带、RRP 线——本就在图上可见）。
   - 即改即存 `LPL3.config.anomalyRule` + 清单 `LPL3.config.anomalyMarks`，保存后 `CONFIG_CHANGED_EVENT` 广播（量价销量缓存等自动失效，同默认店铺先例）。
2. **分析三页（价格走势 / 量价 / 多平台对比）工具行右端放只读状态 chip**：「数据质量 ≥50%」（无隔离时）/「数据质量 ≥50% · 本页隔离 2 点」（有隔离时，琥珀数字）。点击弹 Popover：规则一句话 + 本页隔离点列表（产品 · 周 · 原值 · 环比，点击定位到周）+「查看配置」链接。chip 只读，不在Popover 里改全局值（口径唯一写入口 = 配置页）。
3. **图上隔离态视觉**（见 §5.6 视觉语言表）：主线在隔离点处**断开**；隔离点画**空心圆点**（`mute` 灰描边、白芯、~7px）+ 下方**琥珀胶囊**「疑 −61%」（复用 ↓/↑ 徽标形态，色 `#b45309`）；悬停 tooltip：周号 / 原值 / 对上一有值点环比 / 判定依据（瞬态超阈）/ 按钮组「查看商品页 · 确认真实价格」。
4. **人工豁免闭环**：tooltip「确认真实价格」→ Popconfirm 预览（该点原值与环比）→ 确认后该点回实线、胶囊换蓝「已确认」小标、进清单。反向「标记异常」同构（把规则漏掉的点手动隔离，如持续两周的挂错价）。
5. **表格打标**：价格走势宽表该周「折后价」单元格原值照显 + 琥珀「疑」上标（title 带环比与规则）；计算行（近 4 周环比等）按可信链，隔离周不进均值（同缺价周处理）。
6. **量价页**：面板价格线同款隔离态；被隔离周的成本 / 销毛行显示「价格不可信」空态（不造销毛）；极差卡按可信链，区间内全被隔离时显示「区间内无可信价格」空态；单周明细卡价格行「已隔离 · 原值 USD 389」+ 豁免入口。
7. **预警中心**：扫描基于可信链（隔离点不触发「调价」预警——今天脏点会报假预警，本设计顺带修掉）；prev 链跨隔离点；预警解释卡数据状态位展示「该周价格已隔离」（若回看）。

**低保真示意**：demo 页「方案 A · 全景」标签页——含配置块、工具行 chip、价格线（实线 / 缺采桥 / 隔离空心点 / 已确认点 / 末端待确认点五种状态齐备）、tooltip 卡、宽表打标、量价明细卡与极差卡。

**优点**

- 跨页一致由取数层单点保证（`buildSeries` 打标，四页 + 预警 + 宽表同源），满足 brief 硬要求。
- 口径有唯一所有者（配置页 / 数据运营管理员），版本与留痕天然满足「预览-确认-记录-撤销」。
- 事实层永远可见原值 + 取证链接，「不吞点」；豁免双向、可撤销。
- 顺带消灭「脏点报假调价预警」这一现实缺陷。

**缺点 / 风险与缓解**

- 配置页离分析现场远、可发现性弱 → 缓解：三页工具行只读 chip 常驻（含本页隔离数），点击可达配置；首启用当周生效即有视觉变化（空心点 + 胶囊）自解释。
- 全局一刀切，个别产品持续误报 → 缓解：三类豁免（§5.3）+ 人工清单；不引入按产品阈值覆写（v1，理由 §6）。
- 改口径会改变所有派生数字 → 缓解：chip 常驻提示当前口径；豁免与阈值变更留痕于清单；不静默（图上标注永远在）。

**实现成本**：中（约 2–3 天含双视口实测）。`buildSeries` 判定与 `suspect` 字段、隔离态图元（空心点 + 断线 + 胶囊）、tooltip 豁免闭环、下游过滤（极差 / 环比 / 均值 / 预警 prev 链）、宽表打标、量价空态、Config 块 + 清单 + chip。无新 token（全部复用 `mute` / `#b45309` / 胶囊形态 / `Block` / `ThresholdSlider` 语言）。

### 方案 B：筛选条口径 chip（随筛选持久化 + 进 URL）

**交互说明**：筛选条「取价类型 / 聚合」旁加「异常价 ≥50% ⌄」chip，点开 Popover 选档（关闭 / 30 / 50 / 自定义）；随 `LPL3.filters` v12 持久化并新增 URL 参数 `aq`（与 `agg` 同族）；全站即时生效。

**低保真示意**：demo 页「方案 B · 筛选条入口」标签页（含 URL 变长示意与预警页受影响提示）。

**优点**：就近分析场景、即点即生效；口径随 URL 分享，接收入方数字与发送方一致；实现比 A 略省（无 Config 块与广播）。

**缺点 / 风险**：① 筛选条已承载国家 / 产业 / 产品 / 平台 / 粒度 / 时间 / 币种 / 取价类型 / 聚合，再进一条口径项加重认知负担；② 「谁能改」从管理员扩大到所有人在分析中随手调——不同人不同阈值，同一报表数字不可比，口径漂移风险最高；③ 影响面（预警 / 宽表 / 量价 / 多平台全部跟着变）远大于入口所在页的暗示，用户感知不到；④ URL 参数再 +1，且 `aq` 与 `agg` 一样成为「数字会变的链接」。

**实现成本**：中低。**风险**：口径治理（多人多阈值）+ filters 载荷与 URL 面 widened。

### 方案 C：图表工具条滑杆（仅标注，不剔除）

**交互说明**：`ChartToolbar` 复刻「价格变化提醒」语言：Checkbox 开关 + 滑杆（30–90）+「≥ X%」读数；超阈点画琥珀胶囊 + 空心点，**不进任何计算**；状态为图表视图态（会话级）。

**低保真示意**：demo 页「方案 C · 工具条滑杆」标签页。

**优点**：实现最小（半天级）；与既有滑杆零学习成本；零口径风险（不动数字）。

**缺点 / 风险**：**不解决用户诉求的核心**——「不可采信」的目的是让极差卡 / 环比 / 均价 / 预警不再被脏点污染，纯标注等于把已有的「价格变化提醒」换个阈值，功能重复；且滑杆是视图态，四页各调各的，违反跨页一致硬要求。

**实现成本**：低。**定位**：可作为 A 落地前的过渡，但不推荐单独交付。

## 5. 口径逐项裁定

### 5.1 变化率公式与判定基准

- **公式**：`chg = price_i / price_{i-1} − 1`，**对上一原始有值观测点**，prev 跨缺采延续——与 `alerts.ts:288`、`chartModel.ts:919`、`weekDetail.ts:71` 三处现行口径逐字一致，不发明第二套。
- **涨跌对称**：`|chg| ≥ T` 对称判定。上涨多为挂错 variant / 币种错读，下跌多为配件价串入或闪促——都不可信，v1 不做涨跌双阈值（拍板项 4）。
- **判定对象**：折后价主序列（我司与竞品同规则——脏点不分品牌）；**RRP 序列不判**（参照口径、官方维表，无采集噪声）。
- **粒度**：判定在最终序列的相邻观测点上执行，与粒度解耦——周粒度是主战场（用户口径）；月 / 季桶内行级脏数据仍由既有 5% 守卫兜底，跨桶形态由本规则在月 / 季序列上同样生效。
- **首点不判**（无 prev）；**序列末端候选只标注不隔离**（见 5.2 末条）。

### 5.2 瞬态 vs 持续（连续异常与真实事件的区分核心）

脏点是**瞬态**的（一两周后回到原水平）；真实业务变化（大促档期 / 官方调价 / 清库 / 新档位）是**持续**的水平位移。自动规则据此分叉：

- **瞬态超阈（V 型）→ 自动隔离**：点 i 超阈，且点 i+1 回到上一可信水平（`|price_{i+1} / lastTrusted − 1| < T`）→ 隔离 i，i+1 是干净数据（它只是相对脏点变化大，对可信基线几乎没动）。
- **持续位移 → 不隔离，只标注**：点 i 超阈且新水平维持 ≥ K 个连续观测点（推荐 K=2）→ 判为疑似真实变化：图上琥珀「待核对」胶囊（提示人工确认），**计算照常使用**——错杀真实调价会静默改数字，比漏更糟。人工确认异常后可手动隔离（进清单）。
- **连续异常串**：多周连脏（如挂错价三周）在「持续位移」分支下不会被自动隔离（K 判据放行）——这是有意的保守：连续脏点人工隔离一次即可，自动错杀的代价更高。串中若出现 V 型（脏后回弹再脏），逐段独立判定。
- **序列末端候选**：最后一个观测点超阈时无法区分瞬态 / 持续（未来未到）→ 只标注「待确认」（琥珀空心点，不断线、不进隔离数）——**末端恰恰是用户最常看的一周，绝不能在证据不足时静默剔除它**。

### 5.3 三类豁免

1. **促销带自动放行**：点的周命中大促日历（`dim_promo` 任意档期）**且为下跌** → 不隔离不标注（促销带背景已在图上，双重标注冗余）；上涨命中促销带仍判（大促不涨价）。
2. **RRP 同步放行**：该点相对前点 RRP 发生变化且价格同向 → 官方调价传导，不隔离（RRP 线变化本就可 见）。
3. **人工裁定（双向）**：图上 tooltip「确认真实价格」（豁免）或「标记异常」（手动隔离）；Popconfirm 预览原值与环比 → 确认 → 进 `anomalyMarks` 清单（产品 / 周 / 原值 / 环比 / 动作 / 时间戳），图上留蓝「已确认」小标或琥珀隔离态；配置页清单可撤销，撤销后回到自动判定。符合「预览-确认-记录-撤销」。

### 5.4 检测基准 vs 计算基准（对上一原始周还是上一可信周）

- **检测**对上一**原始**有值点（5.1）——先看真实世界再谈可信。
- **计算**（量价环比 / 预警 prev 链 / 明细卡环比）对上一**可信**点——对脏点算环比得到 +156% 的「回弹」正是要消灭的假信号。跨过隔离点时在明细卡环比值旁加小注「跨 1 个隔离周」（title 展示跳过了哪周）；观察周本身被隔离时环比行显示「已隔离」，不计环比（原值可见）。

### 5.5 下游影响逐项裁定

| 下游 | 现输入 | 裁定 |
|---|---|---|
| 量价极差卡（`rangeSpreadOf`） | 窗口内 `prices` + `pricePointValid` | 加 `suspect` 过滤谓词：隔离点不参与 max / min / 极差率；区间内全隔离 → 「区间内无可信价格」空态；不影响销量轴（销量独立估算） |
| 量价环比 / 明细卡 | 全量域上一桶 | 对上一**可信**桶，跨隔离标注；观察周被隔离显「已隔离 · 原值 USD 389」 |
| 近 4 周环比（宽表） | 窗口内忽略缺价周 | 同款处理忽略隔离周；两窗口之一无可信价 → `—` |
| 月 / 季聚合（`agg`） | 桶内行均值 / 最低 | 隔离周不进月 / 季聚合（判定在目标粒度序列上另有覆盖，双保险不冲突） |
| 宽表事实行 | 原值 | **原值照显 + 「疑」角标**（事实层不删数据，title 带环比与规则） |
| 成本 / 销毛带（量价，模拟） | 价格序列 | 隔离周销毛显空态「价格不可信」（不造销毛） |
| 预警四类 | `priceForSelection` / 各平台最低 | 扫描基于可信链：隔离点不触发「调价」「促销」「平台价差」；「档位间距」取最新**有值且可信**周；解释卡数据状态位可展示隔离状态 |
| 多平台对比 | 每线独立 `buildSeries` | 自动获得打标；每平台线独立判定（A 平台脏不连坐 B 平台）；平台价差预警吃可信后数据 |
| 量价预测 | fixture（`simulated`），不消费真实价格序列 | **当前零影响**（边界如实声明）；接入真实数据后隔离周不入 `input.price` 基准链（`priceFactor` 一路传导） |
| Agent | 只读 | 回复涉及价格统计时在「判断边界」声明「已按 ≥50% 口径隔离 N 点」；改全局阈值 / 豁免走既有确认卡纪律 |
| 行级 5% 低侧守卫 | `implausiblyLowRow` 静默剔行 | **维持现状**（行级与点级是两层：行级拦绝对离谱、点级拦相对形态）；顺带把其行为文档化进「数据质量」块说明句（拍板项 5：是否也升级为可见打标） |

### 5.6 各页一致表现与视觉语言

| 状态 | 图上 | 表格 / 卡片 |
|---|---|---|
| 有值可信 | 实线（现状） | 原值 |
| 缺采 | 彩色虚线桥 `[4,4]` 无点（现状语义，不动） | `—` |
| 隔离（瞬态 / 手动异常） | **断线 + 空心灰点（`mute` 描边白芯）+ 琥珀胶囊「疑 ±X%」** | 原值 + 琥珀「疑」角标；明细卡「已隔离 · 原值」 |
| 待核对（持续位移）/ 待确认（末端） | 实线不断 + 琥珀空心点 + 胶囊「待核对」 | 原值 + 琥珀「疑」角标（title 说明未隔离原因） |
| 已人工确认（豁免） | 实线 + 蓝「已确认」小标 | 原值 + title 记录裁定 |
| 命中促销带 / RRP 同步 | 不额外标（促销带 / RRP 线本身可见） | 原值 |

- 三页（价格走势 / 量价 / 多平台）+ 宽表 + 预警解释同一套语言；预测页不放 chip（fixture 模拟数据，避免误解为已接入）。
- 键盘 / 无障碍：胶囊与空心点是 SVG 图元，等效信息在宽表 / 明细卡 / chip Popover 列表均有文字形态（图表信息必有文字替代）；「确认真实价格」为原生 button + Popconfirm；chip `aria-haspopup="dialog"`。
- 窄屏 390px：chip 文案短形态「质量 ≥50% · 隔离 2」；tooltip 内按钮换行；宽表角标不增列宽（上标形式）。
- 动效：豁免 / 撤销后点位回实线用 160ms 状态反馈；无位移动效；`prefers-reduced-motion` 直跳。
- UI 文案铁律：全程业务语（「异常价格 / 已隔离 / 确认真实价格」），不出现「quarantine / outlier / 数据清洗」类工程词与 AI 味句式。

### 5.7 状态、持久化与权限

- 存储：`LPL3.config.anomalyRule = { enabled: true, thresholdPct: 50 }` + `LPL3.config.anomalyMarks = [{ countryCode, modelId, romram, weekId, action: 'exempt'|'isolate', note, ts }]`。周 id 存周粒度主键；月 / 季粒度下命中其构成周即生效。
- 变更广播：`CONFIG_CHANGED_EVENT`（`lplKeys.ts:21`），量价销量缓存等既有监听自动失效；`buildSeries` 每次调用现读配置，无新增缓存面。
- **不进 URL**：URL 承载「看什么数据」的范围语义（c / i / main / plat / rs / pt / agg）；本口径与「默认店铺」同类（怎么取数 / 哪些可信），默认店铺即不进 URL——分享链接不携带口径漂移，接收入方看到的是自己口径下的数字，chip 常驻使其可发现（拍板项 3 备选进 URL）。
- `LPL3.filters` v12 载荷**零改动**，无 v13 迁移风险。
- 谁能改：全局阈值与清单管理 = 数据 / 运营管理员（配置页角色）；图上逐点裁定 = 分析用户（带确认与留痕）；Agent 只读 + 确认卡。

### 5.8 边界情形

- 区间内全隔离：极差卡空态「区间内无可信价格」（同「无法计算 + 说明可用范围」纪律）。
- 两点点列超阈：无 i+2 可判持续 → 按末端候选处理（标注不隔离）。
- 豁免后又遇新脏点：豁免按点生效，不影响后续判定（链从该点续）。
- 多 SKU 组内均值：`buildSeries` 桶价 = 各色最低价均值，判定在**桶级点**上做（与消费方同粒度）；组内单 SKU 脏价被均值稀释后未超阈属可接受（行级 5% 守卫先拦最离谱的）。
- 悬停 / 取证：隔离点 tooltip 保留商品链接与「暂无快照」状态——查证据正是裁定脏 / 真的主路径。

## 6. 推荐方案与理由

**推荐方案 A。**

1. **它是口径，不是视图**：诉求的落点是「不可采信 → 不参与计算」，改变所有派生数字的规则必须有唯一写入口与留痕——配置页 + 管理员角色是既有架构里为此准备的层（默认店铺 / 对标矩阵同构），B 把它放进人人可改的筛选条是治理倒退。
2. **跨页一致只能单点保证**：判定进 `buildSeries`，价格走势 / 量价 / 多平台 / 宽表 / 预警同源打标，C 的视图态滑杆注定四页漂移。
3. **不进 URL 是默认店铺已验证的先例**：口径随链接漂移会让「同一个链接不同人看到不同数字」的反面（不同链接看似同数字实则不同口径）更隐蔽；chip 常驻 + 配置页留痕比 `aq=50` 更可审计。
4. **保守分叉保护真实业务**：瞬态才隔离、持续只标注、末端不隔离 + 三类豁免 + 双向人工裁定——在「脏点污染计算」与「错杀真实大促」之间，把可逆的错误（多看一眼）留给机器，把不可逆的错误（静默改数字）留给人。
5. **默认 50% 开启**：瞬态 + 豁免规则已把促销 / 官方调价放行，50% 几乎只命中采集事故；30% 更激进可后续按清单误报率下调（拍板项 1）。
