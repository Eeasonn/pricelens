# 设计任务：异常价格阈值配置（2026-11-01，用户提出）

## 需求
新增一个配置：相邻两周（周粒度相邻两个观测点）价格变化幅度超过设定阈值（例如 30% 或 50%）时，判定为「异常价格，不可采信」。

## 需要你设计（只设计，不实现）
1. 这个设置放在哪儿？（全局设置 / 页面筛选区 / 图表工具条 / 按产品或平台单独覆盖？默认值、可选档位或自定义输入、是否持久化/进 URL、谁能改）
2. 不可采信的价格怎么标注？完全不显示，还是其他处理（如断线/虚线、空心点、灰化、角标+悬浮说明、表格里打标并可展开原值）？
3. 必须说清的口径：变化率怎么算（对上一可信周还是上一原始周、涨跌是否对称）、连续异常和「真实大促/新上市」怎么区分或人工豁免、被剔除后对极差卡/环比/均价/销毛/预测等下游计算的影响，以及在价格走势、量价、预测、多平台对比各页面的一致表现。
4. 给 2–3 个方案对比（交互说明、低保真示意、优缺点、实现成本、风险），给推荐方案与理由。
