导入三步（全程约 3 分钟）
--------
① 拷贝 00 里的 PriceLens-Server-20261119 整个文件夹到内部电脑（要求 Python 3.10+，
   安装时勾选 Add to PATH；无需联网装任何依赖）→ 双击「启动PriceLens.bat」
   → 浏览器自动打开 http://localhost:8321
② 「导入配置」→ 选 04 里的 xlsx → 预览确认（服务器模式：配置同时存服务器并自动
   参与后续派生）
③ 「导入数据包」→ 选 02 里的 JSON（或内部 Agent 产出的全量包——117MB 级直接导，
   服务器 Python 引擎派生约 10-60 秒）→ 页面自动刷新 → 数据卡显示
   「服务器数据包（v2 · Python 引擎派生）」+ 原表归一诊断 → 量价页量带悬停应标
   「PSI 真实销量」

内部真实数据接入
--------
内部系统 Agent 按「内部系统数据准备要求」产出 JSON → 同样走「导入数据包」
（服务器模式下即上传服务器）。业务侧只维护配置表（Excel 编辑 → 导入配置；
改完别名/矩阵/字典后点数据包区「用当前配置表重新派生」；系列规则即时生效）。

数据承载与备份
--------
服务器模式：数据在 PriceLens-Server 目录的 data/ 下（pricelens.db = SQLite：
ODS 原样层 + map_* 匹配小表「我们加的派生内容」+ 维表/事实，一眼可分；config.json
= 配置）。备份/迁移 = 拷整个文件夹。单文件兜底模式：数据在本机浏览器 IndexedDB。

常用入口（应用内）
--------
配置页 = 顶栏「配置」：数据包导入/导出/还原、配置表导入导出/模板下载、
        数据诊断（原表归一明细、销量 unmatched 黄条）
数据口径说明 = 顶栏 ？：销量口径、取价渠道、原表模式说明
