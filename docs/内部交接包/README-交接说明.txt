导入三步（全程约 3 分钟）
--------
① 拷贝 00 里的 PriceLens-Server-20261123 整个文件夹到内部电脑（要求 Python 3.10+，
   安装时勾选 Add to PATH；无需联网装任何依赖）→ 双击「启动PriceLens.bat」
   → 浏览器自动打开 http://localhost:8321
   （配置已预置，起服务器即带全量规则，不用先导配置）
② 放数据：把 offers.csv + sales.csv（或 sales.xlsx）放进上一步的 data/ 文件夹
   （格式见 02-数据包/新格式样例-20261123/）→ 约 10–60 秒自动重派生
③ 看结果：浏览器约 15 秒内自动刷新 → 「配置 → 数据」卡显示
   「服务器数据包（v2 · Python 引擎派生）」→ 价格走势页出线
   （也可走「导入数据包」上传 v3 JSON：117MB 级直接导，服务器派生约 10–60 秒）

数据承载与备份
--------
服务器模式：数据在 PriceLens-Server 目录的 data/ 下。源文件（offers.csv / sales.csv /
config_tables.xlsx / config.json）是唯一数据源；pricelens.db（SQLite，24 张表：源层 →
匹配配置层 → 维表 → 事实表）是派生产物，会被自动重建，不要手编。备份 / 迁移 = 拷整个
文件夹。单文件兜底模式：数据在本机浏览器 IndexedDB。
