# PriceLens 主产品经营视图与量价销毛成本设计定稿

| 项目 | 内容 |
| --- | --- |
| 版本 | V1.0 |
| 日期 | 2026-10-31 |
| 状态 | 可进入实施 |
| 适用界面 | 量价走势 |
| 数据策略 | 本期全部使用确定性模拟成本与销毛；暂不讨论真实成本获取链路 |

## 1. 背景与核心决策

当前量价走势会把顶部筛选器中的全部主产品与对比产品铺开。多组选择后，主产品经营分析与组内竞品比较混在同一层级，难以回答“我的产品在当前周期表现如何”。

本次迭代把默认视图改为**主产品经营视图**，并将组内主品与竞品对比降为次级界面。每个主产品在同一个面板内呈现量、价、销毛、成本，但使用主图与窄幅成本销毛带两层结构，不使用四轴图。

已定决策：

1. 量价默认只显示各分析组的主产品，不自动展开对比产品。
2. 1–3 个主产品按数量并排；超过 3 个沿用现有横向浏览，不新增默认组切换。
3. 组内主品与竞品对比使用同一量价卡内的次级视图，一次只展示一个分析组。
4. 销毛与成本只进入量价走势，不在价格走势重复增加入口。
5. 每个主产品使用“价格折线＋销量柱”的主图，以及“单台成本阶梯柱＋单台销毛阶梯线”的窄幅下图。
6. 上下图共享查看窗口、时间轴、缩放、平移、十字线和当前选点。
7. 成本与销毛本期使用确定性模拟数据并明确标注；真实获取与接入不在本期范围。
8. 友商成本不填假数据，竞品成本销毛区域显示“可显示，当前无数据”。

## 2. 范围

### 2.1 本期包含

- 主产品默认面板集合。
- 组内对比次级视图、组切换和返回主产品视图。
- 每个面板独立的成本销毛数据与窄幅图。
- 月度成本与销毛在周/月/季视图下的阶梯展示。
- 确定性销量、成本和销毛模拟规则。
- 空态、异常、响应式、键盘与读屏处理。
- 数据口径说明、测试、浏览器验收与本地单文件同步。

### 2.2 本期不包含

- 价格走势页的销毛成本模块。
- 独立新页面或独立主导航。
- 真实 OBS、IPrice 或竞品成本接入。
- 预测、情景推演或成本预测。
- 跨产品平均价、跨产品成本汇总或跨产品销毛汇总。
- 将四指标画在同一绘图区或共用四根纵轴。
- 改变现有产品选择、渠道选择、时间选择及区间量价摘要的既定行为。

## 3. 主产品默认视图

### 3.1 面板集合

默认仅从每个 `MainProduct` 分析卡提取 `card.main`：

- `card.main == null`：跳过该卡。
- `card.compares`：仍保留在筛选状态中，但不自动生成默认面板。
- 同型号同配置重复项按现有规则去重。
- 面板顺序、渠道选择、币种、价格聚合和查看窗口继续沿用现有逻辑。

布局：

- 1 个主产品：全宽。
- 2 个主产品：两栏等宽。
- 3 个主产品：三栏等宽。
- 超过 3 个：沿用现有横向浏览，不进一步压缩，不增加默认分组明细选择器。

### 3.2 本组对比入口

主产品存在对比产品时，在面板标题区显示轻量文字入口：

```text
本组对比（N）
```

点击进入组内对比次级视图：

- 当前分析卡的主产品与全部对比产品按现有面板规则展示。
- 多分析组时提供组选择器；一次只显示一组。
- 提供“返回主产品视图”。
- 不新增路由、独立页面或全局面板集合。
- 次级视图使用瞬态；切回价格走势或重新进入量价时回到主产品默认视图。

筛选器中的主品与对比选择不因进入或退出次级视图而改变。

## 4. 单面板的四指标结构

```text
┌─────────────────────────────────────────┐
│ 产品药丸 / 平台入口       本组对比（N） │
│ 区间量价摘要（保留现有）                 │
├─────────────────────────────────────────┤
│ 价格折线＋销量柱                         │
│ 主图，使用现有 Chart 与 VolumeBars       │
├─────────────────────────────────────────┤
│ 成本与销毛（模拟）                       │
│ 单台成本：浅灰阶梯柱                     │
│ 单台销毛：深色阶梯线                     │
│ 独立窄幅区域，建议高 144px               │
├─────────────────────────────────────────┤
│ 共享 PanelTimeTrack                     │
└─────────────────────────────────────────┘
```

### 4.1 指标分工

| 指标 | 表现形式 | 纵轴与说明 |
| --- | --- | --- |
| 折后价/RRP | 主图折线 | 沿用现有价格轴、币种与聚合口径 |
| 销量 | 主图柱区 | 沿用现有销量轴、估算标识与上下限设置 |
| 单台成本 | 下图浅灰阶梯柱 | 下图共享“金额/台”轴 |
| 单台销毛额 | 下图深色阶梯线 | 与单台成本同轴 |
| 销毛率 | 当前点读数 | 不增加第三根线或第四根轴 |

销毛率只作为辅助读数，不单独绘制百分比曲线。

### 4.2 成本与销毛恒等式

```text
单台销毛额 = 单台收入 − 单台成本
销毛率 = 单台销毛额 ÷ 单台收入
```

模拟数据必须始终满足以上关系。单台收入为 0 或缺失时，该点整体为 null，不显示伪造的 0% 或负无穷。

### 4.3 时间粒度

- 成本与销毛使用月度值。
- 周视图：同一月份内各周显示同一月度平台。
- 月视图：每个月一个平台。
- 季视图：仍展示季度内各月平台，不把月值强聚成季值。
- 不按渠道拆成本，不把上方价格强拉成月。

### 4.4 时间与选点联动

成本销毛带必须使用与主图相同的时间桶顺序和绘图区横向几何：

- 查看窗口变化时，成本销毛点同步切片。
- 缩放、平移与非同步面板窗口均按现有 `effWins` 规则处理。
- 十字线下标与主图 `hoverIdxs` 一致。
- 当前点主图继续显示价格与销量；成本销毛带显示当月成本、单台销毛和销毛率。
- 不另设独立时间轴，继续使用面板现有 `PanelTimeTrack`。

### 4.5 销量 Y 轴：正常刻度轴＋点击编辑上限

当前右侧竖线看起来像拖杆，但真正可操作的只有顶部数字输入框。为避免错误的交互暗示，本期将销量轴统一改为普通刻度轴，不增加拖杆。

默认形态：

```text
销量（台）
2,000
1,000
0
```

- 轴线使用 1px 浅灰，顶部、中间、底部显示三个刻度与短刻度线。
- 顶部不再显示“最高值”，轴标题统一为“销量（台）”。
- 上限值使用普通文字与等宽数字，不常驻边框；下方以 9–10px 灰字标注“自动”或“手动”。
- 点击上限值后才切换为数字输入框：Enter/失焦提交、Escape 取消、清空恢复自动。
- 非编辑状态不出现框，编辑与键盘聚焦时才显示细边框和全站焦点环。
- 保留现有 `volumeRangeOf` 与 `commitVolumeAxisLimit`，不改变柱高映射、零基线和图表高度。
- 手动上限低于当前数据最大值时，必须显示“超出当前上限”提示及截断柱形，不能让用户误以为柱顶就是实际销量。

## 5. 组内对比与竞品空态

组内对比视图中，所有产品仍可以查看量与价，不禁选竞品。

成本销毛数据只在我方产品有模拟值时展示；没有数据的产品保留相同高度的成本销毛区域，并显示：

> 可显示，当前无数据

规则：

- 不用模拟值填充友商成本。
- 不写“不支持”“不显示”或“数据获取失败”。
- 空态不得改变主图高度、时间轴位置或面板对齐。
- 我方产品即使出现在对比区，也按同一数据规则处理；是否为友商由现有 `isOwn` 判断，而不是由主品/对比角色判断。

## 6. 销量模拟修正

现有模型已经包含 Apple、Samsung 品牌系数和促销系数。本次不是简单继续放大系数，而是修正可解释性。

### 6.1 基础销量

继续沿用：

```text
国家/产业基线
× 品牌强度
× 价格档位
× 配置份额
× 生命周期
× 折扣拉动
× 大促拉动
× 确定性微扰
```

约束：

- 同国家、同档位、同生命周期下，Apple、Samsung 主力产品销量应高于 Huawei。
- 不将品牌优势机械应用到所有档位，避免高端机不合理地超过走量机型。
- 销量继续仅在对应配置有事实在架行的周产生非 null 值。
- 输出继续为非负整数，同一输入必须逐字节确定。

### 6.2 大促区间

复用 `dimPromo` 的真实日期区间，按阶段形成可解释波形：

| 阶段 | 销量规则 |
| --- | --- |
| 预热期 | 小幅抬升，低于正式峰值 |
| 正式大促 | 按促销深度、品牌与档位形成不同峰值 |
| 尾声 | 从峰值回落 |
| 大促后 | 允许短期需求透支 |

约束：

- 促销深度与折扣继续协同，不用随机峰值。
- 不同品牌与配置不能完全同幅、同形。
- 无在架事实、退市或缺货周不得因大促产生销量。
- 确定性微扰由当前约 ±8% 收窄到约 ±3%，避免噪声掩盖大促形状。
- 月/季继续由周值求和，不另造一套月度随机模型。

## 7. 成本与销毛模拟

### 7.1 基本规则

- 以全量价格序列的中位有效价形成产品级参考成本，避免改变查看窗口时成本跳变。
- 成本按月缓慢下降，单月只保留轻微确定性差异。
- 单台收入取对应月份有效折后价均值；月/季聚合价格沿用现有输出，不重复聚合。
- 大促降价时，成本不必同比例下降，因此单台销毛会自然收窄。
- 大促后价格与销毛允许部分恢复，销量允许回落。

### 7.2 可解释场景

| 场景 | 价格 | 成本 | 单台销毛 | 销量 |
| --- | --- | --- | --- | --- |
| 日常 | 稳定 | 缓慢下降 | 稳定或小幅改善 | 平稳 |
| 大促 | 下降 | 基本稳定或略降 | 收窄 | 上升 |
| 大促后 | 部分恢复 | 稳定 | 部分恢复 | 回落或短期透支 |

### 7.3 模拟标识

成本销毛带标题固定为：

> 成本与销毛（模拟）

不得把模拟值写成 OBS、财务事实或真实竞品成本。

## 8. 视觉与响应式

- 成本销毛带使用独立高度，不压缩现有主图绘图区。
- 成本为浅灰阶梯柱，销毛为深色阶梯线；不与品牌价格线争夺颜色。
- 负销毛必须显示零基线，不能通过只取正值隐藏。
- 多主产品各自使用独立成本销毛尺度，不在一张图中叠加多个成本系列。
- 面板过窄时，成本销毛读数允许换行；不新增第二套横向滚动。
- 继续遵守现有最多三面板并排和横向浏览规则。
- 数字使用等宽数字，方向不只依赖颜色。
- reduced-motion 下不使用高度或位移动画。

## 9. 空态与异常

| 情况 | 规则 |
| --- | --- |
| 无成本销毛数据 | 显示“可显示，当前无数据”，保留区域高度 |
| 某月无有效收入 | 该月成本销毛点为 null，不画伪造平台 |
| 单台收入为 0 | 该点整体为 null，不计算销毛率 |
| 销毛为负 | 显示负值与零基线，不截断 |
| 价格构建失败 | 沿用现有异常提示，不伪装为无数据 |
| 无对比产品 | 不显示“本组对比”入口 |
| 空主品分析卡 | 跳过，不产生空面板 |

## 10. 既有能力保持

以下功能不得因本次迭代被重写或删除：

- 产品选择、组内自动匹配与渠道选择。
- 渠道同步、快照恢复与平台徽标。
- 价格类型、币种、粒度与平均价/最低价聚合。
- 主图、销量柱、销量轴设置与 Y 轴设置。
- 区间量价摘要及其与查看窗口/拖选高亮的现有联动。
- 同步/非同步查看窗口、面板拖序与会话态。
- 现有 `PeriodVolumePriceSummary` 和 `periodSummary` 纯计算接口。

## 11. 验收摘要

1. 默认只出现主产品，竞品仅在组内对比次级视图出现。
2. 多组时可进入某一组对比并返回，筛选状态不被改写。
3. 每个主产品能同时看到价格、销量、成本与销毛，且没有四轴混排。
4. 上下图窗口、缩放、平移、十字线和当前点完全一致。
5. 周/月/季下月度成本销毛阶梯正确，渠道切换不拆成本。
6. Apple、Samsung 在可比条件下销量大于 Huawei，大促区间峰值可解释且确定。
7. 成本销毛恒等式成立，负销毛、null 与零收入均正确处理。
8. 竞品不填成本假数据，空态文案准确。
9. 现有区间摘要、渠道同步和窗口状态无回归。
10. 销量轴为三档轻量刻度，点击上限可编辑、清空回自动、Escape 可取消；手动截断有明确提示。
11. 项目标准检查与真实浏览器验收通过，并同步本地单文件版本。

实施任务、接口与测试步骤见配套文档：`docs/superpowers/plans/2026-10-31-pricelens-main-product-margin-cost.md`。
