## 3. 发现的 bug（4 个，全部已修复）

### Bug#1 暂存条 `.lpl-hit` 缺 `position:relative` → 巨幅拦截层吞掉面板药丸点击（交互阻断）

- **复现**：1440 量价页（2+ 面板）→ 点面板头药丸隐藏一个产品 → 暂存条出现 → 点任一剩余面板的药丸
  → 点击被暂存条迷你药丸的伪元素拦截，30s 内无响应；任何被暂存条「覆盖」区域内的交互同样失效。
- **根因**：`.lpl-hit::after { position:absolute; inset:-6px }` 依赖宿主元素自身定位；HiddenTray 迷你药丸
  （及 Chart 裁定浮层内两个按钮）没设 `position:relative`，::after 以页级定位祖先为包含块铺开整层。
- **修复**：三处补 `position:relative`（commit `1b71a45`）。浏览器断言回归通过（隐藏/恢复全链路可点）。
- 截图：`vol-reading-hide1.png`。

### Bug#2 配置页「自定义」档进不去（选中态被拉回，输入框一闪即逝）

- **复现**：配置页 → 数据质量块 →（当前 30%）点 Segmented「自定义」→ 输入框闪现后消失，选中态回到「30%」，
  无法输入自定义阈值。
- **根因**：onChange('custom') 只设了草稿没入自定义模式；Segmented 选中值由 rule 推导（30 → '30'），立即回弹。
- **修复**：补 `customMode` 状态（点自定义即入、提交合法值停留、选回预设档退出、配置广播重读复位）；
  组件测试 5 例钉住（含 5/abc/95 拒绝与「提交后停留」）。commit `1b71a45`。
- 截图：`anomaly-config-block.png`。

### Bug#3 明细卡裁定按钮被邻列文本压住点不到（窄面板）

- **复现**：组内对比 4 面板（每面板 ~1/3 宽）→ 键盘定位到 GW8C 2026W39 → 明细卡出现「确认真实价格」
  按钮 → 点击 → 被「已隔离，不计环比」文本拦截（该文本 120px+ 溢出 1/4 宽的环比格压到按钮）。
- **根因**：裁定按钮嵌在 1/4 宽的折后价指标格内追加一行；四列网格在窄面板下邻列长文本溢出叠压。
- **修复**：裁定按钮移出指标格、独立整行（gridColumn 1/-1）；隔离环比文案压缩两行（语义进 title）；
  按钮套 Popconfirm（与图上入口同款「预览-确认-记录-撤销」）。commit `1b71a45`。
- 截图：`vol-anomaly-detail.png`。

### Bug#4 极差卡「区间内无可信价格」空态不可达（恒真值分支）

- **复现**：量价组内对比 GW8C 面板 → 拖选区间只盖 2026W39（隔离周）→ 价格极差卡整个消失
  （设计应显示「区间内无可信价格」空卡；销量极差卡正常）。
- **根因**：`rangeSpreadOf` 恒返回对象（无可信点时 min/max/spread 为 null），调用侧
  `priceSpread ? 正常卡 : 空卡` 的真值判断永远走第一支。
- **修复**：改为按 `min != null && spread != null` 字段判定；组件测试钉住该场景（含「对象恒真值」的坑注释）。
  commit `1b71a45`。
- 截图：`vol-anomaly-spread-empty.png`。

## 4. 仍未修 / 无需修（说明与原因）

1. **预警解释卡的「该周价格已隔离」状态位未做**：隔离周不再产生任何预警（扫描走可信链），
   解释卡没有可回看的隔离态条目；如需「历史预警回看展示当时隔离状态」属新需求，另轮处理。
2. **裁定入口在图上胶囊 Popover，而非设计稿的「悬停 tooltip 内按钮」**：现悬停浮层是
   pointer-events:none 的只读层（既有架构），tooltip 内已补打标说明行（事实层），裁定改由
   胶囊本位点开（含 Popconfirm 预览 + 查看商品页），能力等价、命中区更大。surface brief 已备案。
3. **裁定后量价面板瞬态（观察列/刷选）复位**：CONFIG_CHANGED_EVENT 会让 FiltersContext 重置卡组、
   面板态随数据刷新回默认列——既有「配置变化=数据刷新」语义，非本轮引入；测试按「刷新后重新定位」验证。
4. **组内对比的隐藏集跨页失义**：viewMode（阅读↔组内对比）本就是瞬态（既有设计），切页回来回阅读视图，
   组内隐藏键随之失义、再进组内对比即清空——与「切换清空」口径一致；跨页保留对阅读视图完全生效（已测）。
5. **多平台视图看不到聚合级隔离点（GW8C 2026W39）**：多平台每条线 = 单店铺独立判定（设计 §5.5
   「A 平台脏不连坐 B 平台」）；W39 的异常来自聚合口径（该周便宜渠道缺采），单店铺线无跳变——符合设计。
6. **React 控制台既有警告**：`border`/`borderLeft` 混用警告（面板根样式在阅读/组内两种分支间切换的既有写法）
   与 antd RangePicker `dropdownClassName` 弃用警告 ×3——均为存量，非本轮引入，无视觉/功能影响，不在此修。
7. **促销放行点入可信链的构造性边界**：若促销降幅超过阈值，档期结束后回升周按规则可成「待确认」候选
   （计算照常、人工可一键确认消掉）。真实数据促销降幅未超 50% 默认档，未出现；单测钉住语义（anomaly.test）。
8. **连续异常串的保守漏报**：贴近脏水平的串内后续点不成候选（宁可漏、人工隔离兜底）——设计 §5.2 有意为之，单测钉住。
