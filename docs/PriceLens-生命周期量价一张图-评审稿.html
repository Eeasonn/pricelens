1到底怎么定价
在天花板与地板之间，参照上一代与竞品，选一个位置
天花板 消费者愿意付多少——核心卖点值不值钱④；竞品卖多少、价差停在哪②；所在价格段大盘是深是浅①
卖贵的前提是有人认：卖点值钱、竞品衬托、档位有水，三者缺一就别硬高开
地板 单台成本及走势⑤；销毛底线与盈亏平衡线⑥——任何价格都不能击穿
成本决定「最低能卖多少」，盈亏线决定「最低该卖多少」
参照 上一代卖多少、怎么涨跌、何时换代③；竞品新品涨不涨、老品守不守②③
消费者对新品的价格记忆来自上一代；能不能跟涨，看竞品先动没动
注意 渠道甩卖全新机时，把二级市场价格纳入对标※
甩卖价会分流预算型买家，拿它对标避免开盘价虚高
决策输出开盘价与档位 · 对上一代的翻涨价幅
例：GT6 799 → GT7 949 高开 13%——竞品普涨②＋上一代托底③＋成本上移⑤，目标销毛 26% 对照盈亏线 33%⑥
2怎么判断销量是否异常
SO 不孤立看——四个对照，对照不上的才是真异常
跟自己比 走势对照上市预期与周趋势⑨——首销期的偏差要最快发现、最快纠正
对照基准是上市时定下的预期节奏：首销看首销曲线，在售看周趋势
跟货比 进了货卖不动＝渠道压货⑩；卖得动但没货＝缺货截断，不是需求弱⑪
压货是「渠道进了、终端没动」；截断是「需求还在、货没了」——两种处置完全不同
跟大盘比 随大盘一起跌是行情①；大盘稳、独自跌，才是自己的问题
用大盘规模与价格段结构判断：跌，要跌得跟行情一致
跟事件比 竞品上市、换代分流③；大促后自然回落⑫
事件窗口内的下跌先归因事件；窗口过后仍弱，才按真异常处理
判断输出异常归因：需求走弱 / 渠道压货 / 缺货截断 / 竞品冲击 / 换代分流 / 大促扰动
3要不要价促、调价
先归因，再动作；动价之前，先算值不值
动价 需求走弱、价格仍有空间——小步调价或价促，改的是位置⑧②
调价改长期位置，价促开短期窗口——看问题是长是短，选对应工具
动货 缺货与供应受限——不是价格问题，补货与配额解决，不轻易动价⑪
缺货时降价＝白让利：量上不去，利润还少了
清库 库存高、DOS 高、临近换代——加速价促清库，对照二级市场甩卖价※防踩踏⑩③
清库价要贴着二级市场价走：定高了清不掉，定低了被渠道甩卖反向踩踏
跟随 竞品价格动作破价差警戒——跟随或观望②；大促档期借势放大动作⑫
价差警戒＝竞品成交价与自有产品价差的偏离超出历史正常区间
值不值 促销带来的增量是否真增利——销毛仍守底线才算数⑥⑦
增量核验：多卖的量带来的利润，要盖过让利损失与执行投入
动作输出调价 / 价促 / 补货配额 / 观望不动——每一次动作都带归因与增量核验
闭 环
实际结果：SO⑨ · 销毛⑥ · 库存 DOS⑩ → 复盘：预测偏差 · 促销真实增量⑦ → 沉淀：成为下一代的「上一代参照」③ → 回到下一代的定价
卖了多少台 × 每台赚多少 = 生意结果，价格是同时撬动两者的核心杠杆
