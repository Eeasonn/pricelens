# 大盘图表 · GFK 看板复刻（market-board-gfk）

> 视觉权威：`pricelens/DESIGN.md` + `pricelens/src/theme/tokens.ts`。父级契约：`PRODUCT.md` 数据边界与证据规则、`docs/PRICE-LENS-DESIGN-HANDOFF.md`。
> 本面为**独立预览面**（`pricelens/marketboard-preview.html`，仅 dev 可达，不进构建入口），全部为新增文件，等待 Eason 审阅后决定合并落点。

## 目标

复刻 GFK 分析看板的三张大盘图（参考截图：IMG_9476 / IMG_9368 / IMG_9371，阿联酋穿戴大盘口径），作为 PriceLens 的大盘上下文视图，风格与现有系统（Vercel 语言：白卡、hairline、墨+单蓝+限量琥珀）一致，品牌用既有品牌数据色。

## 范围与边界

- 三张图：
  1. **核心档位品牌份额趋势**（档位 × 月度 100% 堆叠柱 + 顶部大盘容量条）——提供「全档位」与「单档位筛选」两种形态（卡头 Segmented 切换）。
  2. **品牌份额趋势**（两年月度 100% 堆叠柱 + 大盘销量线 + 大盘 ASP 线）——无档位筛选。
  3. **各品牌核心档位结构同比变化**（品牌 × 档位矩阵小图，本期 vs 去年同期 + 同比标注 + 大盘整体列 + 摘要行）——无档位筛选。
- 数据：`marketBoardData.ts` 按产业（智能穿戴 / 智能手机 / 平板电脑）各一份，**互不相同**；穿戴档位结构与品牌份额锚定 GFK 阿联酋穿戴截图；手机/平板参考 IDC·Counterpoint 2025 公开口径整理。全部为模拟数据，卡片带「模拟数据」徽标与口径说明。
- 不做：档位联动、GFK 的合并/细分档位切换、导出、真实数据接入（后续由 Eason 指定落点后再接）。

## 信息层级（自上而下）

- 卡头：图题（14/600/ink）+ 来源徽标（模拟数据 · 口径参考 GFK）+ 右侧本图视图控件（仅图 1 有档位 Segmented）。
- 图 1：顶部档位带（档位名 + 各月大盘容量万台，与 GFK 同构）→ 100% 堆叠柱（段内 ≥4% 标百分比，白/墨自动反色）→ 月份轴 → 底部品牌图例。全档位形态下档位分组以极浅底色（3% 墨）交替区分。
- 图 2：100% 堆叠柱（≥10% 标注）+ 大盘销量线（蓝 #0070f3，右轴万台，标签在点下方）+ 大盘 ASP 线（琥珀 #f5a623，独立隐藏量纲，标签在点上方）→ 底部图例。
- 图 3：摘要行（档位增长 TOP3 + HUAWEI 最大涨落档位，由数据计算生成）→ 品牌列横滚网格（大盘整体列打头）：列头为本期/同期总量与同比，列内每档位一对细柱（本期品牌色 / 同期浅墨）+ 右侧同比标注（涨蓝 / 跌琥珀 / 新增灰）。
- 卡底：要点摘要一行（12/mute），由 `marketBoardModel` 从数据计算，非手写文案。

## 状态语义

- 数据状态恒为 simulated：徽标文字「模拟数据」，tooltip 展开口径说明；不与真实数据混排。
- 同比：正=蓝 #0053c2、负=琥珀 #b45309、同期为 0=灰「新增」，一律带 ± 号；与全站涨蓝跌琥珀语义一致。
- 段内标注只服务阅读，交互细节一律进 tooltip（品牌、份额、贡献量万台）。

## 证据与数据呈现

- 每张卡有文字摘要或口径行，满足「图表必须有文字摘要或数据表替代」。
- 单位：销量万台、ASP 为 USD（与 GFK 看板一致），在卡头徽标 tooltip 与摘要中说明。
- 不出现「我司」；HUAWEI 作为品牌名使用并沿用品牌红 #c7000b。

## 响应式与可访问性

- 图表卡内 minWidth（图 1 全档位 1080 / 图 2 1080 / 图 3 列宽 148 横滚），窄屏卡片横向滚动，不裁切数值。
- 图例文字 ≥11px；轴刻度 12（caption）；堆叠段标注 10px 仅在可容纳时显示。
- 切换档位/产业仅重绘 option（受控 setOption），不做整卡重挂。

## 例外与有意取舍

- 图 2 的 ASP 线沿用 GFK 做法：独立隐藏量纲 + 逐点数值标注，不占用右轴刻度（避免三轴）；tooltip 给出真实值。
- 图 3 以「最新锚点月 vs 去年同期」同比（2026-08 vs 2025-08），与图 1 锚点月一致；GFK 截图中的 2026-06 口径不采用。
- 品牌色：已登记品牌走 `brandColorOf`；GARMIN/AMAZFIT/GOOGLE/WHOOP/LENOVO/OPPO/VIVO 等落入稳定扩展色板；OTHERS 固定中性灰 #a1a1a1。
- 复用了 `useEChart` 模式但在本目录内置一份（pricing/SchemeCharts 未导出该 hook）——合并落点确定后可再统一收口，避免本次改动触碰现有文件。
