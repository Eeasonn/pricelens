# 大盘图表 · GFK 看板复刻（market-board-gfk）

> 视觉权威：`pricelens/DESIGN.md` + `pricelens/src/theme/tokens.ts`。父级契约：`PRODUCT.md` 数据边界与证据规则、`docs/PRICE-LENS-DESIGN-HANDOFF.md`。
> 2026-11-03 起已接入主导航：分析壳页 id `marketboard`（标题「大盘走势」），入口在 `ChartContentBar`「量价走势」之后；页面组装见 `src/pages/MarketBoardPage.tsx`（口径行 = 模拟数据徽标 + 单位说明 + 产业 Segmented，产业选择会话级保留 `LPL3.view.marketboard.industry`；产业切换三卡按 key 重挂）。dev 预览面 `pricelens/marketboard-preview.html` 保留，仅作无壳审阅入口。

## 目标

复刻 GFK 分析看板的三张大盘图（参考截图：IMG_9476 / IMG_9368 / IMG_9371，阿联酋穿戴大盘口径），作为 PriceLens 的大盘上下文视图，风格与现有系统（Vercel 语言：白卡、hairline、墨+单蓝+限量琥珀）一致，品牌用既有品牌数据色。

## 范围与边界

- 三张图：
  1. **核心档位品牌份额趋势**（档位 × 月度 100% 堆叠柱 + 顶部大盘容量条）——天然为全档位视图，无档位筛选。
  2. **品牌份额趋势**（两年月度 100% 堆叠柱 + 大盘销量线 + 大盘 ASP 线）——**提供「全档位」与「单档位筛选」两种形态（卡头 Segmented 切换）**；单档位模式下条带只显示该档位容量（档位内无均价口径），柱为该档位内的月度品牌份额。
  3. **各品牌核心档位结构同比变化**（品牌 × 档位矩阵、本期 vs 去年同期 + 同比标注 + 大盘整体列 + 摘要行）——无档位筛选。
- 数据：`marketBoardData.ts` 按产业（智能穿戴 / 智能手机 / 平板电脑）各一份，**互不相同**；穿戴档位结构与品牌份额锚定 GFK 阿联酋穿戴截图；手机/平板参考 IDC·Counterpoint 2025 公开口径整理。全部为模拟数据，卡片带「模拟数据」徽标与口径说明。单档位月度序列：锚点月精确取档位数据，早期月按「品牌整体份额相对首锚点月的漂移因子」推导后归一（`marketBoardModel.tierShareTrendAt`）。
- 不做：档位联动、GFK 的合并/细分档位切换、导出、真实数据接入（后续由 Eason 指定落点后再接）。

## 信息层级（自上而下）

- 卡头：图题（14/600/ink）+ 来源徽标（模拟数据 · 口径参考 GFK）+ 右侧本图视图控件（仅图 2 有档位 Segmented）。
- 图 1：顶部档位带（容量数字 + 档位名两行，与主图之间留足呼吸，档位名不压 100% 刻度线）→ 100% 堆叠柱（段内 ≥4% 标百分比，白/墨按 WCAG 亮度自动反色）→ 月份轴 → 底部品牌图例。档位分组以极浅底色（3% 墨）交替区分。
- 图 2：双带布局——上方条带为大盘销量线（蓝 #0070f3）与大盘 ASP 线（琥珀墨 #b45309），各占条带上下半区、逐点标值；下方为 100% 堆叠柱（≥12% 标注）→ 底部图例。单档位模式：条带仅一条该档位容量线（占满条带），图例/摘要随之切换。
- 图 3：摘要行（档位增长 TOP3 + HUAWEI 最大涨落档位，由数据计算生成）→ 品牌列横滚网格（大盘整体列打头，hairline 分隔）：档位标签只在首列出现一次（GFK 同构），列宽 200、图高 400（行距约 63px，对照原版）；列头为本期/同期总量与同比；列内每档位一对 9px 横柱（本期品牌色 / 同期浅灰）各自标值；右半区为同比曲线（细灰线穿档位行，x 位置编码同比幅度、钳在 −100%~+300%），点旁标注涨蓝 / 跌琥珀 / 新增灰，本期同期皆无的档位曲线断开、不标注。
- 卡底：要点摘要一行（12/mute），由 `marketBoardModel` 从数据计算，非手写文案。

## 状态语义

- 数据状态恒为 simulated：徽标文字「模拟数据」，tooltip 展开口径说明；不与真实数据混排。
- 同比：正=蓝 #0053c2、负=琥珀 #b45309、同期为 0=灰「新增」，一律带 ± 号；与全站涨蓝跌琥珀语义一致。
- 段内标注只服务阅读，交互细节一律进 tooltip（品牌、份额、贡献量万台）。

## 证据与数据呈现

- 每张卡有文字摘要或口径行，满足「图表必须有文字摘要或数据表替代」。
- 单位：销量万台、ASP 为 USD（与 GFK 看板一致），在卡头徽标 tooltip 与摘要中说明。
- 不出现「我司」；HUAWEI 作为品牌名使用并沿用品牌红 #c7000b。

## 响应式与可访问性

- 图表卡内 minWidth（图 1 1160 / 图 2 1160 / 图 3 = 60 + 列数 × 224 横滚），窄屏卡片横向滚动，不裁切数值；卡头 Segmented 在窄屏下自身横滚。
- 图例文字 ≥11px；轴刻度 12（caption）；堆叠段标注 10px 仅在可容纳时显示。
- 切换档位/产业仅重绘 option（受控 setOption），不做整卡重挂。

## 例外与有意取舍

- 图 2 的销量 / ASP 线不与柱共用绘图区，而是放在上方独立条带、各自隐藏量纲逐点标值（GFK 原版是叠在柱上；此处为避免与柱内标注打架而分带，与图 1 的容量条带手法一致）。单档位模式下不提供 ASP（无档位内均价口径），诚实留空而非估算（第二波起该规则同样适用于自定义价带态，见下）。
- 图 3 以「最新锚点月 vs 去年同期」同比（2026-08 vs 2025-08），与图 1 锚点月一致；GFK 截图中的 2026-06 口径不采用。图 3 柱长按列内最大值独立缩放（GFK 同构，否则小品牌柱仅数像素不可读），跨列比较依靠列头绝对值与同比标注；同比曲线的 x 映射将同比钳在 −100%~+300%（GFK 的 +6400% 类极端值同样被压到曲线带右端，用着色标注传达精确值）。
- 品牌色：已登记品牌走 `brandColorOf`；扩展色板对 WHOOP/OPPO/LENOVO 落出的品红/紫/玫红大面违「清爽」基调，本面局部收敛为深绿 #166534 / 绿 #15803d / 深青 #0f766e；GARMIN/AMAZFIT/GOOGLE 等沿用扩展色板；OTHERS 固定中性灰 #a1a1a1。
- 复用了 `useEChart` 模式但在本目录内置一份（pricing/SchemeCharts 未导出该 hook）——合并落点确定后可再统一收口，避免本次改动触碰现有文件。

## 第二波（2026-11-04，Eason 拍板两项：④多线新卡 + ②自定义价带）

四卡纵排新顺序：①核心档位品牌份额趋势 → ②品牌份额趋势 → **④品牌份额走势（多线，新）** → ③各品牌核心档位结构同比变化；页签/导航不动。

### ④品牌份额走势（BrandShareLinesCard，新增）

- 目标：每月各品牌份额变化一图多线（Eason：品牌份额走势要做，但单拉新卡，不动图 2）。口径恒为**全档位大盘**（本卡不加档位筛选，卡头口径行注明「全档位口径 · 单位：份额 %」），数据 = `marketBoardModel.trendSeries` 既有序列，无新数据口径。
- 图上只留数据与控件：图例为 echarts legend（图外底部居中、roundRect、可点显隐，与图 1/2 同款风格）；每线仅标最新月端点（品牌名 + 份额值，`labelLayout hideOverlap` 避让——「挤就只标最新月」的落地）；25 个月逐月刻度会与右缘端点标值抢宽，x 轴每季一刻度（interval 2），精确月份看 tooltip。
- 层级：HUAWEI 线 2.5px + 端点标签 600 字重（华为主视角最强层级）；竞品 1.5px；OTHERS 中性灰虚线降存在感。卡底要点由 `brandLinesSummary` 从锚点数据计算（最新锚点月份额前三 + 较去年同期变化最大两品牌），非手写文案。

### ②品牌份额趋势 · 档位控件升级（自定义价带）

- 控件：原「全档位/单档位组」Segmented 升级为**「全档位（默认，=大盘总量）+ 自定义」**（Eason：不固定 100–200/200–300 这类固定组）。自定义态追加两个 antd InputNumber（最低价/最高价，step 50、钳在产业价域内）+ 状态文字（如「自定义 $25–50」；退化输入用 warningInk 琥珀提示并保留上一自选带）；点「全档位」一键恢复。控件语言与卡头既有 Segmented/输入控件一致，窄屏在卡头 extra 内横滚/换行。
- 数据口径（模拟插值，数据诚实）：锚点数据仍按固定档位组织，自定义带 = **覆盖的 50 美元格子聚合**。`marketBoardData.tierCellsOf(ind)` 把产业有限价域参数化切分为 ≤50 美元格子（起步 = 最小有限档位边界：穿戴 25 / 手机 100 / 平板 200，即「25 起步按产业现状调整」；开口档 <起步 / >上限 不参与）；粗于 50 的档位按**档内均匀分摊**折算到格子，锚点月总量守恒、确定性、无随机数，`marketBoardData.ts` 数据层注释已标明该模拟插值口径。早期月沿用既有确定性插值（容量按首锚点月占比折算、份额按品牌整体漂移因子），与单档位模式同源。应用后上方销量线与下方堆叠柱按自定义带重算；**带内无均价口径（档位格无价格锚点），琥珀 ASP 线诚实留空**——与原单档位模式同一取舍，不估算、不新增「精确」暗示（页面本有「模拟数据」徽标）。
- 输入校验：值吸附 50 格边界、钳在价域内、min>max 自动换序、min===max 视为退化保留上一自选带并提示；非法输入钳制在模型层 `clampBand` 纯函数落地并被单测锁定。产业切换四卡按 key 重挂，档位控件回默认全档位。图 1 的 6 档位组与图 3 形态不变；原单档位模式模型函数（`tierTrendSeries` 等）保留导出与单测，仅 UI 入口按拍板移除。
