# 明细表「分析提示」条（detail-insight-strip）

2026-11-28 · Eason 拍板 · 作用面：价格看板图下宽表（对标视图「价差与明细」、分列视图「分列价格明细」，均为 `TrendTables`）

## 目标

在明细表当前组的表体上方，用几张小卡点出值得看一眼的数值变化，让用户一键定位到列、展开计算过程，或交给 Agent 追问。提示是**本地确定性规则**，不调用模型，也不自动发 LLM 请求。

## 规则与阈值（`chart/PriceTrend/insights.ts`）

数据 = 宽表同源的 `groups / buckets / fourWeekChanges`。「有价」= 折后价非空且未被异常守卫隔离；缺价桶保持缺失，不插值。

| 规则 | 级别 | 触发 | 标题 |
| --- | --- | --- | --- |
| crossover | 4 | 对比品与基准在首、末「双方有价」桶上的价差符号相反 | `{对比} 已低于/高于 {基准}（−4.1%）` |
| gapShift | 3 | \|末价差 − 首价差\| ≥ 5 个百分点，且没有翻转 | `{对比} 相对 {基准} 的价差由 +3.0% 扩大/收窄到 +9.2%` |
| priceMove | 2 | 近 4 周环比 \|值\| ≥ 5%（与表内 chip 同源） | `{产品} 近 4 周降价/涨价 6.2%` |
| coverage | 1 | 可见区间有价期数 < 50% | `{产品} 可见区间仅 n/m 期有价，结论需谨慎` |

- 价差 = (对比 − 基准) ÷ 基准。基准与宽表价差区相同：对标视图用主分析产品，分列视图用临时基准。组内没有基准时只跑 priceMove / coverage。
- 同一对产品出现 crossover 时，不再给 gapShift。
- 排序：先按级别降序，同级再按 \|幅度\| 降序。边界：恰好 5pp / 5% 触发，4.9 不触发。
- 数据状态：周度折后价写「真实（周度平台实抓）」；ZA 月度写「真实（运营商小册子）」，与选品弹窗「来源状态」用同一表述。当前链路没有 simulated 价格。

## 位置

渲染在组页签下方、横向滚动表格**之外**，不进 grid，时间列对齐不受影响。一次只显示当前页签组的提示，切组时提示条重新挂载。

## 卡片

- 头行：「分析提示」+ 条数 + 问号 Tooltip（「规则提示：由当前图表同源数据按固定阈值计算，不调用模型；解释与建议请用「追问」」）。默认最多显示 3 张，超出部分收进「另有 N 条 / 收起」。
- 卡片：白底、`shadow.l1` hairline、`radius.card`，最小宽 240px，多张卡横向排开、放不下就换行。标题 13px ink；数字 11–12px，用 `font.family` + tabular-nums。
- 动作：
  - 「定位」：给目标列的全部单元格铺 inset `selectSoft` 背景，并把该列横向滚到冻结区右侧。高亮 1.5s 后复位；开启 reduced-motion 时为静态高亮，下一次交互时清除。
  - 「计算过程」：就地展开 输入 → 筛选 → 公式 → 舍入 → 输出，内容是真实数值与桶名。
  - 「追问」：调用 `openAgent('dock', 「请解释这条分析提示并给出核查建议：{title}。结构化上下文：{JSON}」)`。
  - 「✕ 忽略」：本会话内隐藏这张卡，记在 sessionStorage `LPL3.ui.insightDismissed`（id 数组）。id = kind | seriesKey | otherKey | bucketId，重新渲染后保持不变。
- 无障碍：整条为 `role="region"`，`aria-label="{组名} 分析提示"`；每个动作都是 button，可访问名称里带提示标题。

## 边界

- 纯确定性计算，不调用模型；只有用户点「追问」才会进入对话。
- 文案只陈述数值变化，不写「因为 / 导致 / 由于」，不做因果判断。
- 没有提示时整条不渲染；页面上没有 AgentProvider 时，「追问」按钮隐藏，其余动作照常可用。
