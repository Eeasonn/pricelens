# 页头搜索 · Agent 快速筛选入口

## 2026-11-27 · 负责人决策

Mode: Operate. 页头搜索框成为 Agent 的**快速筛选入口**：用户输入「要比什么」，下拉里直接给出可核对的筛选预览，按 Enter 应用、可撤销。搜索不再默认跳进对话面板；只有「为什么 / 怎么办」类问题才提供转到对话。

## 解析规则（`agent-stable/intentFilter.ts · parseFilterIntent`）

- 纯函数、确定性，不调用模型；在 `buildFilterPatch`（币种 / RRP / 最近 N 周 / 国家 / 产品）之上追加。
- 品牌词（Apple/苹果/iPhone、Samsung/三星、Honor/荣耀、Xiaomi/小米、Huawei/华为，以及该产业维表里的任何品牌键或展示名）只用来限定竞品范围；没点名竞品品牌 = 不限定。点名产品本身的品牌不算限定。
- 「同档 / 同档位」+ 已识别产品：主品现价落档（`tierPrice.currentPricesByGroup`，USD），同档其他品牌**每品牌只取价格最接近的一款**，登记来源 `tier`，卡片自动匹配关。
- 「上一代 / 换代」：数据包 prevGen 映射（`groupsFromPrevGeneration`）带出，来源 `manual`；查不到时写说明「数据包未登记 {型号} 的上一代配置」，不猜。
- 无产品的档位词：`$600-800`、`600~800`、`600-800美元`、`旗舰`（顶档）、`入门`（底档）。区间必须与 `tierBandsOf` 阶梯完全一致，否则说明「未识别的价格档位」。该档每个我司组各成一卡；点名品牌的同档竞品**全部**带上，按 |USD 价差| 最近分给我司卡（`tierBoard.cardsFromBoard`）。「华为旗舰」只看我司。
- 同档 / 上一代没点名产品也没档位词时，沿用当前主分析产品。
- 视图词：「分列 / 按品牌」→ 分列·品牌；「按系列」→ 分列·系列；「按档位分列」→ 分列·档位；「代际 / 生命周期 / 换代对比」→ 代际。
- 问题判定：含 为什么 / 原因 / 怎么办 / 建议 / 是否应该 / how / why / 问号。
- `FilterPatch` 新增 `viewMode`、`columns`；预览标签「视图：对标 / 分列 / 代际」「分列依据：品牌 / 系列 / 档位」。

## 预览 UX

- 输入去抖 150ms 后计算。补丁有变化且超出「单个型号命中」（同档 / 上一代对比、档位成卡、视图切换或 ≥2 个产品）时，下拉顶部显示「筛选预览」区块，两种模式都显示。
- 区块：`role="region"` `aria-label="筛选预览"`；逐行「字段：之前 → 之后」，换行，最多两行，完整内容在 title；口径说明用小号 mute 文本；主按钮「应用 ⏎」，问题类给次按钮「转到对话深度分析」，否则是安静文字链「在对话中分析」。
- 白底 + hairline 卡，全部取 tokens；数字用界面字体 + tabular-nums；不加紫色、渐变或新动画。
- 普通型号搜索保持原样：选产品写 mains，自动匹配照旧。

## 应用与撤销

- 有预览时 Enter 直接应用；用 ↑↓ 显式选中某条产品后，Enter 仍选该产品。
- 应用 = `actions.set(patch)`，关闭下拉，页头搜索框下方显示内联状态条「已应用筛选 · 撤销」（`role="status"`）。状态条保留到用户撤销或开始下一次输入，不依赖短暂 toast。撤销只恢复本次补丁涉及的键（应用前的值），不动其他筛选。
- AI 模式空态建议换成真实数据拼出的筛选模板：「{我司旗舰} 同档 苹果 三星」「华为旗舰 vs 上一代」「$600-800 手机 按品牌分列」。我司旗舰 = 当前国家 / 产业现价 USD 最高的我司组；没有就用静态建议。对话面板的追问建议不变。

## ⌘/Ctrl+K

- 价格走势页挂着页头搜索时，⌘/Ctrl+K 聚焦并展开搜索；其他页面照旧打开 Agent 面板。实现：搜索挂载时登记 `state/headerSearchFocus.ts` 句柄，AgentContext 的全局快捷键先问句柄。
- 「问 PriceAgent」按钮仍是对话入口。

## 边界

- 解析确定性、可解释，不调用模型，不编数据；档位一律按现价落档（USD）。
- 只在用户确认（Enter / 点「应用」）时写筛选；「转到对话」只交出问题本身，不写筛选。
- 价格、证据和结论仍由看板和 Agent 现有引擎计算。
