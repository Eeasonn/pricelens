## 目标

让操盘者在单页完成「展示层结论 → 推演假设 → 验证修正 → 会议结论」闭环：
基于大盘（纯时间序列 + 行业事件）、量价参考（历史参照）得出基线 SO，经库存验证（SI 月计划 + 刚性 min 修正）回写主图；成本销毛为链路末端独立推测。全部数值为演示（fixture），生产话术呈现。

## 页面结构（五层，自上而下）

1. **主图 + 摘要**（视觉重心，只露最终结果；2026-11-04 晚评审大减法后定稿）：历史实柱 + 预测虚柱（虚线描边）+ 上一代同周龄参考线 + 价格线（历史实线/预测虚线）+ 库存修正周琥珀描边微痕 + 手调墨色菱形（原因选填，填了才内联标注）+ 产品级小事件锚点 + 促销=轴下日期标注。**把握帽/黑线/档位线/档期色带/分区灰底与「实际｜预测·向未来」说明均已下线**（预测区靠虚柱虚线本身区分）；X 轴刻度 = 全站日历周格式 `2026W33`（复用 PriceTrend `axisTickPlan` + `shortBucketLabel`）。悬停出「本周考量」构成；点击/Enter 微调（**原因选填**）。摘要四格：总销量 / 大促峰 / 库存上限修正 / 预测期销毛。
2. **量价参考**（历史参照，纯历史无预测段）：上一代同期（受控选择器，写入 `prevGenReferenceId` 进入主链，比值校正默认参照）+ 友商同期（仅对照与回放，不改基线）；参照事实锚与主图小事件同源色系。
3. **大盘 · 总量总线**（2026-11-04 评审重构：月粒度 4 季；同日拍板证据信任 v2）：历史月度线 + **未来 4 个季度逐月预测线**（季度基线自上而下月形分布——季内三月合计恒等季度基线 ×3 容量守恒，前两季与既有 AI q4/q1 同源同值，季度与月度永不两套数字）；X 轴月标签 = 全站月视图日历格式 `YYYY-MM`（「今天」文字标签已删，分界虚线保留）；**图表占左 2/3 主视觉 + 事件区右 1/3**（上=AI 候选事件 Top5 占位[抓取逻辑另议]，下=人工事件极简三字段[起始时间/时长/幅度，名称选填]）；**按月可调 = hover/Tab+Enter 预测月 → 证据浮框（四层：头部基线/生效 → 趋势行近 6 个月环比 sparkline → 月形行去年同季三柱+算例 → 「调整此月」就地切换调整表单两态；含事件/手调月顶部复算提示）**（调整后指数/增减幅两式，原因选填），调整季度经季内三月均值同步主链（还原回 AI）；hover 月同时图上双锚点临时高亮（趋势源段近 6 个月衬带 + 去年同位圆环 + 其余线段降透明，移开即恢复，零常驻元素）；月中事件按日均摊（`monthCoverageRatio`，衰减固定递减）；事件在图上=轴下次要标记，不占主视觉；周口径行业事件四件套与主图修正段保留。
4. **库存验证**：SI 按月给入 = 唯一人工输入（卡头格子行，2026-11-04 二轮精简，月内均分到周）；定序 = 基线 SO → 反算 DOS/库存（近 4 周均销）→ 健康判定（DOS 70–90 天 + 降幅 20%/30%，预警解释，**阈值未核定** chip）→ 刚性修正 `min(基线 SO, 可售)` 回写主图；`supplyCapped` 保留截断事实（手调不覆盖）；主图只显最终值 + 琥珀描边微痕。**图面契约（2026-11-04 二轮精简）**：图上只留库存柱 + 渠道 DOS 线 + 轴刻度——全流程 DOS 改库存柱悬停读值、70–90 健康带与 50 格线不上图（判定规则层保留在输出框与链路条 title）、SI 不上图；与成本销毛卡**左右两列编排**（`data-lpl-forecast-grid`，≤760px 单列退化，共享 index.css 既有规则）。
5. **成本销毛**：链路末端独立推测（月版本成本 + 主图价格），单位 `$M`，不回写主图；定位 = **经营结果**（由上述量价与成本推导，成本仅是是否调价的参考、不进模型输入；对销毛不满意回头调量价——2026-11-04 评审拍板）。

## 主图事件联动（两类入口）

- **大盘卡**只收行业级事件（三折叠 / 地缘 / 汇率 / 行业成本）。
- **主图**收产品级小事件（竞品上市 / 营销价促 / 自家品挤兑），录入时弹参考品事实回放（四类解释场景：友商促销 / 自家营销 / 自家品挤兑 / 大促降价，全部历史事实段），幅度按回放预填可改，锚点与参考卡事实同源色系。

## 信任与话术纪律

- AI 推测处一律挂 AI 标：「AI 推测 · 可改」→ 人工改后「人工确认」；AI title 必须说明当前是本地确定性的「季节 × 趋势」规则基线（未调用任何 Agent/模型服务）。
- 证据信任 v2（2026-11-04 晚拍板）：删概率语言、上证据语言。大盘卡三层各司其职——徽章本体说「这是推测、可改」（hover/点击展开三步链：样本 → 两个规律 → 外推，含算例，零新增常驻元素）；hover 月度浮框说「这个月的道理」（算例 + 近 6 个月趋势 sparkline + 去年同季月形小柱）；图上双锚点答「来源在哪」（趋势源段衬带 + 去年同位圆环，hover 临时）。趋势窗口 = 近 6 个月实际段（`workbenchModel.MARKET_TREND_WINDOW_MONTHS`），环比/月形/算例数字全部出自模型导出（`marketTrendWindow` / `marketMonthShape` / `computeMarketMonths`），UI 不另算；季度基线外推链（同季比 × 年度趋势比）为主链口径、结构不动，两套读数同出 workbenchModel 并在口径注释显式声明。
- 手调必填原因，原因内联标注主图手调处；**推演纪要 / 生成纪要 / 另存情景已删除**，替代物 = 「复制关键假设」（结构化纯文本：范围与模拟状态 → 模型版本 → 季度基线与覆盖 → 行业事件 → 上一代参照 → 产品事件 → SI → 手调及原因 → 库存规则 → 结果摘要）。
- UI 禁词：因子 / 约束 / 置信区间 / 无约束需求 / 我司（工程字段 `unconstrained` 允许）。
- 生产话术：无 demo/教学腔叙事段落；模拟标识分级轻量（页首 `DataStatusBadge` 一处 + 各卡轻量「模拟／模拟历史」）；「演示实际」UI 话术为「实际」；范围行写「固定样本 · 不随全局筛选联动」。
- 阈值未获业务核定：UI 用「阈值未核定」轻量 chip，正文不写「待拍板」。
- 库存修正话术 = 「库存上限修正 / 按可售量修正 / 修正周」；不做「刚性砍 / 打折」表述。

## 状态与交互语义

- 实际 = 实线实柱、预测 = 虚线虚柱；缺数显示「—」，实线不跨缺失段（跨缺灰虚），缺数不造 0。
- 会话草稿：`usePageViewState` 键 `forecast.workbench.<modelVersion>`，读写经 `normalizeWorkbenchParams` 校验；跨页往返保留；「重置基准」只清当前版本草稿。
- 页面入共享分析壳（`showFilters=false`），单 `aria-current`；页内不显示会被误解为联动数据的 FilterBar。
- 图上只留数据与控件；无可点击项的图例不得标注「点击切换」；说明文字收副标 / title / 口径行。
