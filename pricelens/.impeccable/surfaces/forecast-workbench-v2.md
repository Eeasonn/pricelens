# 量价预测 · 推演工作台 v2（forecast-workbench-v2）

> 路由 `page = 'forecast'`（`pricelens/src/pages/ForecastPage.tsx`）。
> 正典状态：2026-11-03 晚书面纲领对齐版（提交 28ce1ea）+ 生产化修复计划
> `docs/plans/2026-11-03-forecast-workbench-multi-agent-plan.md`（WP0–WP7，本文随 WP0 同步最新拍板）。
> 本文为审计与实施正典；与历史讨论记录冲突时以本文与实施计划为准。

## 目标

让操盘者在单页完成「展示层结论 → 推演假设 → 验证修正 → 会议结论」闭环：
基于大盘（纯时间序列 + 行业事件）、量价参考（历史参照）得出基线 SO，经库存验证（SI 月计划 + 刚性 min 修正）回写主图；成本销毛为链路末端独立推测。全部数值为演示（fixture），生产话术呈现。

## 页面结构（五层，自上而下）

1. **主图 + 摘要**（视觉重心，只露最终结果）：历史实柱实线 + 预测虚柱虚线 + 上一代同周龄参考线 + 价格线右轴 + 大促档期背景带 + 今天分界 + 把握度帽（修正周 ±2% 窄 / 其余 ±8%）+ 库存修正周琥珀描边微痕 + 手调墨色菱形（原因内联小字）+ 产品级小事件锚点。悬停出「本周考量」构成；点击/Enter 微调（原因必填）。摘要四格：总销量 / 大促峰 / 库存上限修正 / 预测期销毛。
2. **量价参考**（历史参照，纯历史无预测段）：上一代同期（受控选择器，写入 `prevGenReferenceId` 进入主链，比值校正默认参照）+ 友商同期（仅对照与回放，不改基线）；参照事实锚与主图小事件同源色系。
3. **大盘 · 总量总线**：单条季度线 2025Q1 连贯到当前实际，向后只预测下一季（2026Q4 当前季估读 → 2027Q1 下季预测目标）；推演第一版 = 纯时间序列（周期性季节 × 全局性趋势，AI 推测 · 可改，AI 基线 ghost 对照）；人工两条修改路 = ①直接改预测格 ②行业级事件四件套（起周[周粒度，可落历史段=纯解释标记] + 时长 + 峰值幅度 + 衰减[递减默认/恒定]）。
4. **库存验证**：SI 按月给入 = 唯一人工输入；定序 = 基线 SO → 反算 DOS/库存（近 4 周均销）→ 健康判定（DOS 70–90 天 + 降幅 20%/30%，预警解释，**阈值未核定** chip）→ 刚性修正 `min(基线 SO, 可售)` 回写主图；`supplyCapped` 保留截断事实（手调不覆盖）；主图只显最终值 + 琥珀描边微痕。
5. **成本销毛**：链路末端独立推测（月版本成本 + 主图价格），单位 `$M`，不回写主图。

## 主图事件联动（两类入口）

- **大盘卡**只收行业级事件（三折叠 / 地缘 / 汇率 / 行业成本）。
- **主图**收产品级小事件（竞品上市 / 营销价促 / 自家品挤兑），录入时弹参考品事实回放（四类解释场景：友商促销 / 自家营销 / 自家品挤兑 / 大促降价，全部历史事实段），幅度按回放预填可改，锚点与参考卡事实同源色系。

## 信任与话术纪律

- AI 推测处一律挂 AI 标：「AI 推测 · 可改」→ 人工改后「人工确认」；AI title 必须说明当前是本地确定性的「季节 × 趋势」规则基线（未调用任何 Agent/模型服务）。
- 手调必填原因，原因内联标注主图手调处；**推演纪要 / 生成纪要 / 另存情景已删除**，替代物 = 「复制关键假设」（结构化纯文本：范围与模拟状态 → 模型版本 → 季度基线与覆盖 → 行业事件 → 上一代参照 → 产品事件 → SI → 手调及原因 → 库存规则 → 结果摘要）。
- UI 禁词：因子 / 约束 / 置信区间 / 无约束需求 / 我司（工程字段 `unconstrained` 允许）。
- 生产话术：无 demo/教学腔叙事段落；模拟标识分级轻量（页首 `DataStatusBadge` 一处 + 各卡轻量「模拟／模拟历史」）；「演示实际」UI 话术为「实际」；范围行写「固定样本 · 不随全局筛选联动」。
- 阈值未获业务核定：UI 用「阈值未核定」轻量 chip，正文不写「待拍板」。
- 库存修正话术 = 「库存上限修正 / 按可售量修正 / 修正周」；不做「刚性砍 / 打折」表述。

## 状态与交互语义

- 实际 = 实线实柱、预测 = 虚线虚柱；缺数显示「—」，实线不跨缺失段（跨缺灰虚），缺数不造 0。
- 会话草稿：`usePageViewState` 键 `forecast.workbench.<modelVersion>`，读写经 `normalizeWorkbenchParams` 校验；跨页往返保留；「重置基准」只清当前版本草稿。
- 页面入共享分析壳（`showFilters=false`），单 `aria-current`；页内不显示会被误解为联动数据的 FilterBar。
- 图上只留数据与控件；无可点击项的图例不得标注「点击切换」；说明文字收副标 / title / 口径行。
