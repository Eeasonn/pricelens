## 目标

让操盘者在单页完成「展示层结论 → 推演假设 → 验证修正 → 会议结论」的闭环：
基于大盘 / 成本销毛 / 量价参考得出预测销量，经库存验证修正，最终主图 + 关键假设 + 调整记录一张图截图即会议结论。

## 两条铁律（第三轮拍板）

1. **展示与推演分离**：品牌份额 / Top6 / ASP / 领跌剔除验证只属于**展示层**（量价走势页与大盘看板）；
   推演层**只要总量总线**——下探到品牌/品会循环论证（Top6 的预测又依赖量价）。
2. **顺序执行解决循环论证**：库存验证**不在预测链上游**——先由大盘、成本销毛、量价参考三张小图得出
   预测销量 → 喂给库存看板做**验证性分析** → 判定健康 → 销量打折修正 → 回写主图。主图只呈现最终结果，
   不露中间第一版预测。

## 信息层级（自上而下）

1. **主图（视觉重心，只露最终结果）**：主品周销——历史实线实柱 + 预测虚线虚柱 + 参考线（上一代上市
   同期，灰虚）+ 把握区间帽（窄=把握大）+ 库存修正段（琥珀描边 + 与「不含库存限制」细虚线的分叉差值）
   + 价格线右轴 + 大促档期背景带 + 今天分界。悬停预测周出「本周考量」构成（各来源影响幅度）。
2. **大盘 · 总量总线（工作台形态）**：左图 = 去年 Q1 至今的双线对照（去年线 vs 今年线，**季度粒度**，
   同比不下钻到周——大促周序逐年漂移）；右栏 = 参数面板——
   - QoQ / YoY 降幅（先按「去年直接抄 + 叠加今年自然变化」生成，**AI 判断标注 · 人可改**）；
   - 关键事件（影响**幅度 + 时间**两参数；衰减曲率不做；事件分界见下）；
   - **理由栏**：每个值旁写「为什么这么推」——圆桌会议讨论后截图贴 PPT 的关键假设载体。
3. **量价参考（可多个）**：上一代上市同期 + 友商当年促销等多个参照小图并列（预测参考不止一个）。
4. **成本销毛**：月版本成本阶梯 + 预测销毛柱（复用走势页 MarginCostCard 形态）。
5. **库存验证看板（最后一步）**：输入 = 渠道库存绝对值 + 渠道 DOS + 全流程 DOS + **人工 SI 计划**
   （唯一的新输入，其余来自上游预测）；输出 = 健康判定 + 打折系数（回写主图）。
   图形态 = X 时间桶 / 左轴两条 DOS 折线（渠道蓝实 + 全流程灰虚）/ 右轴渠道库存柱 + SI ▼（与走势页
   InventoryDosCard 同构，加预测段虚化）。
6. **推演纪要**：每次调整自动留痕（谁 / 改了什么 / 为什么）；手调强制填原因；「生成纪要」输出
   主图 + 当前考量 + 调整记录的独立文档（KIMI 加固版已实现导出原型，可移植）。

## 库存健康判定（演示规则，待业务确认）

- DOS 合理带（手机）：70–90 天；
- 库存相对上月均值降幅 ≥ 20–30% 判异常；
- 两条件均满足 = 健康（不修正）；DOS 达标但库存骤降（或反之）= 打折修正（9 折 / 8 折两档）；
- 判定基于**预测的** DOS / 库存（假设上游预测销量 + SI 计划推演），页面上与走势页实测图明确区分。

## 事件分界（重申，两轮一致）

- **大盘图事件** = 影响整个行业（开天辟地）：折叠屏阵营、三折叠、地缘冲突、内存暴涨；
- **竞品图事件** = 常规迭代与竞品动作：iPhone 18 Pro、Galaxy 年度迭代、竞品促销；
- 两类事件入口分置，不混排。

## 状态语义（沿用 simple-v1）

- 演示/模拟数据恒带 `simulated` / 「演示」琥珀徽标（PRODUCT.md 数据边界）；AI 判断值带可改标注
  （图标 + 「AI 判断 · 可修改」title，人工改动后标注转「人工确认」）；
