# Volume price cohesion

## Decision

量价走势采用一套连续的阅读骨架：产品身份带 → 价格/成本/销量同一面板 → 面板底部时间轨。工具层只承载全局显示设置和显眼的销毛成本开关；时间轴同步属于时间轨操作，固定在第一张面板时间轨左侧并与轨道带垂直居中。

本轮选定 A 版同轴单层方案。价格和成本继续使用上层绘图区，销量固定使用底部量带，图层说明集中在工具行，面板不增加独立卡片或额外补充图。

## Interaction rules

- 销毛成本是我司面板的经营口径开关，保持“模拟”状态标签，未开启时仍可一眼发现；组内对比不可用时保持禁用并给出原因。
- 时间轴同步只在分离面板显示。所有面板为同步状态时共用查看窗口，关闭后各面板独立调整。
- 量价走势默认平滑折线；用户在图表设置中主动选择阶梯后保留该选择。
- 稳定版与迭代版共用同一组件和几何规则，时间轨按钮不能回到顶部工具行。

## Visual rules

- 每张面板保留统一的价格线、可选成本面积、销量柱和底部时间轨，内部间距保持一致。
- 时间轨左侧为固定控制槽，第一张面板放同步按钮，其余面板保留同宽占位以保证各轨道对齐。
- 颜色沿用 tokens：品牌色只用于数据线，蓝色用于选择状态，琥珀只标记模拟数据。
- 不新增渐变、发光或装饰性阴影；用 hairline、浅表面和稳定的列间距建立连续性。

## Completion checks

- 价格、成本、销量和时间轨形成一条垂直阅读路径。
- 切换同步、销毛成本、折线样式时面板高度不跳动。
- `npm --prefix pricelens run design:check`
- `npm --prefix pricelens run design:lint`
- `npm --prefix pricelens run typecheck`
