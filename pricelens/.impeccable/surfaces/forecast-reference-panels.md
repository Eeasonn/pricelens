# 量价预测 · 参考卡多面板 + 历史事件补录（forecast-reference-panels）

> 隶属 `forecast-workbench-v2` 页面的层②量价参考卡；本文记录 2026-11-04 二轮重构
> （A5）的局部决策。权威优先级低于 PRODUCT.md / DESIGN.md 与用户当前拍板。

## 目标

量价参考卡与量价走势页（`&p=volume`）的面板体系完全同构：图（量柱/价格线/双轴/
档期带/事件锚/悬停浮窗/拖选读数）、产品筛选方式（动态面板增删）、时间轴（共享
时间轨）全部一致；**唯一差异 = 历史事件补录**——量价页只标大促（预标锚），这里
允许用户为已发生的量价变化补记原因（「作业草稿」语义，会话内）。

## 范围

`pricelens/src/pages/forecast/ReferencePanel.tsx`、`ReferenceVolumeChart.tsx`、
`ReferenceEventComposer.tsx`（新建）及对应测试。`volume/**` 只读复用
（VolumeBars / PointerShield / trackColors / 轨道宽度策略），不改模型与主链接口
（`prevGenReferenceId` 受控语义保留）。

## 信息层级（卡内自上而下）

1. SectionHead「上一代上市同期 / 友商同期量价」+ IoBar（不变）。
2. 智能弹框 transient 条（不变，条目定位改按面板）。
3. 面板区工具行：左 = 「历史事件补录：为已发生的量价变化补记原因（会话内草稿）」
   小字；右 = 「＋ 添加参考」下拉（池内未添加产品，分组「上一代 · 进主链 /
   友商 · 对照」）。
4. 单一横滚容器内的面板网格：≤2 均分一行；>2 不折行横滚（每格恒为可视宽 1/2，
   同量价页轨道宽度策略，minWidth 880 保可读下限）。
5. 面板区底部**共享时间轨**（对齐 `volume/PanelTimeTrack` 视觉：trackColors 轨道
   + 选中窗 + 两端拖柄 + 整段平移 + 键盘微调），控制全部面板窗口；52 周全池内
   滑动，最小 8 周。放横滚容器内保持与面板列对齐。

## 面板头（对齐量价页明细卡身份区语言）

品牌色点 + 产品名胶囊 → 链路徽标（「进主链 · 基线校正」蓝 /「对照 · 不影响主图
基线」灰）→「补录 · 会话内」轻量 chip →「＋ 补录事件」→「× 删除」（至少保留
1 个面板）。上一代面板存在时主链指向它；删除上一代面板 = 主链回退默认参照
（`prevGenPool[0]`），徽标随实际指向切换。

## 历史事件补录（与预标锚的唯一差异）

- 入口 = 面板头「＋ 补录事件」→ `ReferenceEventComposer` 弹层（Popover）：
  ①事件类型五选（竞品上市/我司上市/促销投放/挤兑/其他，色与既有锚点同源）；
  ②周选择两式 = 下拉选周 +「在图上点选」（点选态弹层收起、面板顶提示条
  「点击图上某周完成补录」，点击周后弹层回归带值）；③说明必填；④
  「仅本次会话 · 历史补录」标识。
- 提交后：锚点上图（虚线 + 方形锚，type 色，与预标锚同语言，title 带「补录」
  前缀与说明）+ 图下名录（分组「预标 / 补录」，补录可删）。
- 存储 = ReferencePanel 卡内会话 state（key 含面板产品 id），刷新即清；不进
  params、不写主链、不参与模型——纯解释性标注。

## 状态语义

- 双轴刻度常显（左量右价，与量价页一致）；缺采周不造 0（柱不画/实线断开/灰虚
  桥接/读数「—」）；拖选区间各面板独立（同量价页非同步语义）；窗口共享联动。
- 补录与预标靠文字区分（「补录 ·」前缀 / 名录分组），不靠颜色单独表达。

## 响应式行为

1440/1280：≤2 面板均分；>2 横滚。390：卡内横滚（minWidth 880），页面级无横向
溢出；共享时间轨随横滚容器平移，保持与面板列对齐。

## 例外

- 生命周期周（上市周序 W1…W52）为相对周龄刻度，非日历桶；共享时间轨刻度用
  `W{n}` 文本 + `panWindow`/`hideOverlappingTicks`（helpers 纯函数复用），
  不走 `axisTickPlan` 的日历口径。
- 面板构成与会话草稿同层级（组件 state，刷新回默认两面板），不进
  `usePageViewState`——与 A1 槽位口径一致，避免与「重置基准」产生双源。
