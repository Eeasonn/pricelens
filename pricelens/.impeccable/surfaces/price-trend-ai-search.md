# 价格走势 · AI 快速搜索

## 2026-11-12 · 双渠道搜索浮层整理

Mode: Operate. 两版共用 `components/Search/PriceSearchSurface.tsx` 展示层，保留各自产品检索、SKU 选择、国家解析、Agent 交接与语音逻辑。

- 任务顺序：输入 → 产品或 AI 模式 → 执行。产品模式仅显示一组产品行；AI 问题建议只出现在 AI 模式，消除空查询的重复产品 chips。
- 产品行以型号为主，品牌、默认配置和颜色为辅；原始 SKU id 仅用于内部选择与键，不进入可见文案。多 SKU 选择保留在原生“可选规格”展开区。
- 长问题以最多三行预览与固定分析按钮呈现；完整内容保留在输入值和预览 title 中。无产品结果的转 AI 按钮也保持固定文案，不把长问题铺成大块按钮。
- 浮层宽度最多 420px，按输入框位置与视口边缘定位，窄屏留 16px 边距；只在实际内容超高时纵向滚动。局部全子树 border-box、可收缩网格与换行先解决宽度，横轴裁切仅作为容器边界保护。
- 配色、字号、间距、圆角、阴影取运行时 tokens。输入焦点保留清晰单层边框/轮廓，移除多层蓝色光环。
- 空查询显示最多四条可见产品；有查询最多六条。上下键与 Enter 只作用于可见结果，IME 组合输入不能提交，活动项自动进入列表可见区。Tab 可以访问结果、规格展开和每个实际 SKU。
- 稳定版现有自然语言提交会通过 buildFilterPatch 交接筛选，迭代版按现有只读流程交接；本次布局修正不改这项渠道行为差异，也不将其作为新的产品规范。
- 浏览器回归发现迭代版国家代码子串误判（Pro → RO、Samsung → SA）；仅完整国家代码或明确国家名可覆盖当前国家，保留 `R 国 pura90spro` 等显式输入。
- 验收：两版空态、长型号/配置、无结果、AI 长文本、规格选择、键盘/IME；390/768/1440px 下浮层与内部列表均无横向溢出；required check 与双渠道构建通过。

以下为原入口的历史决策；本节覆盖其中产品 chips、浮层尺寸实现与动效归属的旧描述。稳定版保持静态，迭代版沿用原有 reduced-motion 感知的开合与内容过渡。

## 目标与范围

- 在共享页头的国家筛选器右侧加入一枚常驻的单框快速搜索入口。
- 仅在“价格走势”页（`dashboard`）渲染；稳定版与迭代版共享同一入口，其他页面保持原样。
- 首期支持两条清晰路径：本地产品检索并切换主分析产品；把价格问题交给现有只读 PriceLens Agent。

## 信息层级

1. 输入框：搜索产品、品牌或价格问题；显示 Search/AI 分析两种模式。
2. 输入为空：给出轻量示例，提示“搜索产品或让 AI 分析当前价格”。
3. 有输入：本地命中产品优先显示品牌、型号、配置和“来自当前国家 / 产业”的范围；AI 模式显示一条可执行的分析入口。
4. 结果状态：加载或运行只用简短文本“正在读取价格数据…”；不展示模型内部推理。

## 视觉与交互决策

- 延续白底、hairline、6px 控件圆角、浅蓝 selected/focus 和墨色主文案；不新增 AI 紫色、渐变或发光。
- AI 感只通过紧凑的 Robot 图标、`AI` 标签和状态文案表达；不使用持续脉冲或循环呼吸动画。
- 输入支持键盘：`⌘/Ctrl+K` 在价格走势页聚焦，`Esc` 关闭结果层，`Enter` 在 AI 模式发送问题。
- 结果层使用平面白底 + L2 阴影，最大宽度 420px；窄视口占满可用宽度，不裁切关键文案。
- 产品命中点击只写入现有 `FiltersContext.mains`，不改变平台、币种、时间和图表口径；AI 入口复用 `AgentContext.openAgent`，保持 Agent 只读、证据优先和可追溯约束。

## 数据与状态边界

- 产品命中来自 `dimProduct`，按当前国家和产业过滤并按型号去重；配置选择使用该型号第一条真实 SKU。
- 没有命中时明确显示“暂无本地产品命中”，并提供“让 AI 分析”兜底。
- 结果层不伪造价格、销量或证据；任何数值结果由现有图表 / Agent 计算并带现有数据状态。
- `prefers-reduced-motion` 下不依赖动画，保留即时 focus 和打开状态。

## 功能演进与动效决策

- 空态给出三条价格问题建议，点击后切到 AI 分析并预填问题；产品模式支持上下键循环、回车选择当前命中，鼠标悬停同步命中态。
- 产品命中只写入 `mains`；AI 分析打开 Agent 并立即提交一次只读请求，不在搜索框内复制一套聊天记录。Agent 的运行状态由现有面板承担，搜索入口保持轻量。
- 迭代版（`PriceTrendSearch.tsx`）GSAP 只负责有语义的瞬间：搜索面板打开时 200ms 入场，结果内容变化时 120ms 交叉淡化，关闭时 140ms 退场；Agent 面板负责滑入/淡出、消息上移和结果卡片错峰。Robot 图标保持静态，不做持续背景粒子、渐变或思考链动画。
- 稳定版（`PriceTrendSearchStable.tsx`，2026-11-07 整合后按通道并存）GSAP 只负责有语义的瞬间：面板从页头下方进入、结果区域交叉淡入，以及搜索交给 Agent / 筛选条时的短暂交接。不做 AI 图标脉冲、持续背景粒子、渐变或思考链动画。
- 使用 `gsap.matchMedia()` 监听 `prefers-reduced-motion`，减少运动并保留即时可见反馈；effect 退出时 `mm.revert()`，避免切页或重新过滤留下残余 tween。
- AI 提交后保留原问题、打开 Agent 并立即开始只读运行，让快速搜索真正一键完成；重新聚焦搜索框可看到“正在读取价格数据… / 结果已在 Agent 面板生成 / 分析未完成 · 可重试”三种状态；失败信息使用 `role=alert`，重试仍回到同一个 Agent 请求。
