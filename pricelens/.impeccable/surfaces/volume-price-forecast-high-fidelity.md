# 量价走势与量价预测 · 高保真原型

## 目标与模式

- 模式：Operate。面向国家 / 产业负责人、定价经理、经营分析人员和管理者。
- 目标：用两个共享范围与证据口径的视图完成「确认范围 → 看量价事实 → 解释影响 → 做预测草稿 → 回到证据」；把讨论稿里的输入与输出分开，避免把供给约束误读成需求走弱。
- 交付：`design-proposals/pricelens-volume-trend-forecast-hifi.html`，独立单文件评审原型；不改变正式 React 路由、数据口径或根目录离线产品包。

## 信息层级

1. 设计总览：讨论点映射、因果模型、页面规格、口径、交互契约、响应式与待拍板项。
2. 量价走势：大盘（同比与剔除验证）→ 品牌与 Top 品 → 价格策略与影响 → 量价 → 库存 → 成本销毛。每卡同时给图和固定结论栏，不把管理结论藏进 Agent。
3. 量价预测：主量价图与经营摘要 → 大盘需求与档期 → 库存与成本销毛 → 竞品对标与自家挤占 → 推演纪要。
4. 预测主图是视觉重心；下方小图是参考与操作面。先形成不含库存限制的市场需求，再按可售库存修正，最后进入销毛。

## 图表与状态

- 华为价格线使用 `#c7000b` 且最粗；竞品使用稳定品牌色；历史实线实柱，预测虚线虚柱。
- Mate 80 参考线按同周龄贯穿 W37–W52；预测段参考仍是已发生历史映射，不是未来实际。
- 库存卡使用库存柱 + 渠道 DOS + SI；走势页另有全流程 DOS。DOS 必须与库存同读，不能单独解释为“库存充足”。
- 库存修正周、缺口、摘要、库存小图标记均由当前情景计算；未触发时不保留固定的 W50 描述。
- 把握区间只表达演示模型假设：供给修正 ±2%、一般参考 ±8%、自家挤占 ±12%；不宣称校准后的统计置信区间。
- 全稿数值显式标为演示；走势页为“演示 · 混合数据”，预测页为“演示 · 模拟预测”。
- DOS（天）= 库存 ÷ 近 4 周平均周销 × 7；销毛（万美元）= 周销（万台）×（价格 − 成本），换算百万美元再 ÷100。

## 关键交互

- 历史窗口：只改变大盘与量价图的查看范围，不改写历史，不显示预测。
- 剔除验证：点击品牌后显示剔除后的同比与方向性判断，不把同期相关写成确定因果。
- 预测草稿：大盘滑杆、档期、大事件、资源、竞品事件和自家承接联动主图、库存、成本、摘要和逐周数据表。
- 竞品事件：原生 dialog 展示推荐历史交叉关系；可改选参考、幅度和周期，取消不应用，应用后同步来源与实际影响周。
- 单周手调：预测柱支持点击和 Enter / Space；调整原因必填，主图标记、数据表、tooltip 与纪要一致。
- 撤销：恢复上一次考量快照。另存情景仅写本机 localStorage，不写业务系统。
- 导出：生成独立 HTML 纪要，包含当前摘要、考量、库存修正周和全部调整原因，并保留演示边界。
- 渠道缺货：库存图的 DNS 标记支持 hover 与键盘打开风险说明；默认不常驻多渠道线。

## 响应式与可访问性

- 桌面优先；≤1100px 结论栏下移、双卡改单栏；≤680px 筛选与摘要单列，图表只在自身容器横向滚动。
- 三个主视图使用 tab 语义与方向键；按钮有可见 focus；开关暴露 checked；滑杆保留原生键盘行为与 aria-valuetext。
- 对标与微调使用原生 dialog，支持焦点约束、Esc 关闭与焦点返回。
- 主图提供逐周数据表，其他图表提供相邻文字摘要；状态不依赖颜色单独传达。
- `prefers-reduced-motion` 下保留即时状态反馈，移除过渡动画。

## 与旧 simple-v1 的关系

本原型是对现有 `forecast-simple-v1` 的扩展探索：新增“参考对象、库存柱 + DOS + SI、渠道下钻、输入→输出可见、手动原因纪要、品牌与 Top 品、剔除验证和自家挤占”，不把旧简单版四因子限制当作最终页面契约，也不把演示数据当作当前已接入能力。
