# 南非运营商手册数据局部决策

## 目标

为南非 Vodacom 运营商手册建立独立的数据口径和筛选入口。它与周度电商事实共用应用壳、证据卡和稳定/迭代构建通道，但不共用周度价格计算规则。

## 数据 profile

- `countryCode = ZA`。
- `sourceKind = operator-booklet-monthly`，原生粒度为月，界面锁定“月”。
- 平台固定为 `VODACOM SHOP`，不渲染可切换的平台选择。
- 合约价格必须选择 `24` 或 `36` 期，默认不代选。没有分期期数时显示待选择状态，不参与价格聚合。
- 一次性买断单独使用 `prepaid` 口径，不与月供行混算。无价格行保留为证据状态，不作为零价。
- 运营商手册数据必须包含 `period_id`、`term_months`、`price_type`、`offer_id`、`source_document` 和 `review_status`。月供、买断、无价格三类记录不能通过字段推断互相转换。
- 在月度事实模型和复核状态落地前，旧事实包中的 ZA 周度行只保留在原始压缩包用于审计，不进入运行时 `factPriceWeekly`，因此不会被产品树、图表、告警或价差计算读取。

## 证据门禁

附件当前 `gate_status = FAIL`，663 个 offer 仍为 `SUMMARY`，没有 `PASS`。在两轮视觉核验完成、型号规格补齐、未匹配项处理前，数据只进入待复核区，不进入 `real` 事实包、告警、竞品价差或折扣计算。

## 交互

- ZA 选中后，筛选条显示“运营商手册 · 月度”和“平台 VODACOM SHOP”。
- 分期期数使用 24 / 36 的 Segmented 控件，必须有明确选择。
- 页面和图表摘要显示来源、月份、期数和“待复核”状态。缺失快照显示待补证据。
- 稳定版和迭代版使用同一 profile、状态字段和口径校验。迭代版可以展示更多诊断，但不能改变月度、期数和证据门禁。

## 后续接入边界

当 gate 通过后，新增 `FactPriceMonthly` 或统一观察表接入月度事实。现有 `FactPriceWeekly` 保持周度电商契约。禁止为适配南非而把月度数据插值成周，或把月供与一次性买断折算成同一个价格字段。
