# Agent 模型服务（配置分块 + 面板模型选择器）· 局部决策

日期：2026-11-27。属正式产品面，仅在本机服务器模式（`isServiceMode()`）出现；离线单文件与在线 Pages 模式保持现状，不出现任何新界面。

## 目标与范围

让使用者在配置页接入并切换 Agent 的叙述模型，并在 Agent 面板输入框下方看到当前模型、随手切换。

- 数据边界：全部状态在本机服务器（`GET/POST /api/agent/providers`、`/api/agent/active`、`/api/agent/models`、`/api/agent/test`）。浏览器不落盘任何密钥或模型配置，不新增 localStorage 键；密钥只在「输入 → POST」这一段存在于组件内存，保存成功即清空。
- 预置清单单一来源：`src/agentService/providers.generated.json`（models.dev 生成，不手改）。配置界面优先用服务器返回的 `presets`，本地 JSON 只作类型与兜底。
- 「当前模型」是机器级服务器状态：切换只发一次 `POST /api/agent/active`，下一次运行生效；不新建会话、不清输入、不中断进行中的运行。

## 信息层级

### 配置分块「Agent 模型服务」

本页首个「左列表 + 右详情」实现（既有分区都是纵向分块）：

- 左列固定 264px：搜索框 + 服务商列表。每项 = 单字符徽标 + 名称 + 配置状态点与文字。自定义恒排最后；即将支持的服务商可见但不可选。
- 右列自适应：名称与一句话说明 → 外链 → 表单（API Key → 模型 → 高级设置）→ 按钮区 → 状态区。
- 右列内侧再分两栏：左边是表单，右边（280px）是三句静态说明（模型负责什么 / 何时生效 / 密钥存在哪里），只陈述服务器已实现的事实；1280 以下说明移到表单下方。
- 表单字段顺序即填写顺序：密钥（本地服务不出现）→ 模型下拉（「获取模型列表」在旁）→ 高级设置（服务地址，默认收起；自定义服务商因地址必填默认展开）。
- 左右两列用 1px hairline 分隔，整块共用配置页白卡、`radius.card` 与 `shadow.l1`，不另起卡片嵌套。

### Agent 面板模型选择器

- 位置：输入框下方工具栏左侧，原键盘提示文字之前；不改变发送 / 停止 / 最新按钮的位置与状态。
- 触发器 = 供应商徽标 + 模型名 + 状态点，高度与同排按钮一致（32px；窄屏 44px 触控目标）。宽度不足时与提示文字自然换行，不截断按钮。
- 下拉 = antd Dropdown + Menu，按服务商分组，每项带状态点，当前项带对勾；末项「管理模型服务…」跳配置页本分块。
- 下拉浮层挂在 Agent 面板内（不是 body）：抽屉 / 全屏 / 窄屏是模态，AgentThread 会把面板以外的节点置为 inert，挂到 body 的浮层下次会被一起禁用。浮层是一张白卡（`color.canvas` + `radius.card` + `shadow.l5`，直接取 token），菜单与底部说明 / 失败原因在同一张卡里；菜单区超高时自己滚动，说明固定在底部。
- 不使用 toast：切换结果由触发器文字变化直接表达；失败原因写在下拉内。
- 键盘与焦点（菜单按钮惯例）：Enter / 空格 / 上下方向键展开；展开后焦点落在当前模型上，方向键在菜单内移动，Enter 选择，Esc 只收起下拉并把焦点还给触发器（Esc 不再冒泡——AgentThread 在 document 上的 Esc 处理会关掉整个面板）；选完模型焦点回到输入框，Tab 离开菜单时焦点先回触发器再自然往后走。点到浮层外面收起时不抢焦点。

## 状态语义

状态永远由文字承载，颜色与色点只作辅助。

| 状态 | 文字 | 色点 / 颜色（均取自 `tokens.ts`） |
| --- | --- | --- |
| 未配置 | 未配置 | `color.mute` |
| 已保存未测试 | 已保存，尚未测试 | `color.link`（已配置语义，与配置页「已配置」蓝标签同源） |
| 已连接 | 已连接 · 时间 · 延迟 | `color.alert.evidence.verified`（已核实语义） |
| 连接失败 | 连接失败：原因 | `color.error` |
| 已停用 | 已停用 | `color.mute` |
| 当前使用中 | 当前使用中 | `selectSoft` 底 + `selectSoftInk` 字（选中语义） |
| 即将支持 | 即将支持 | `color.mute` |

- 面板选择器警示态：「本地引擎 · 未配置模型服务」，`warningSoft` 底 + `warningInk` 字（需要关注），点击直达配置页。**发送按钮不禁用**——Agent 有本地确定性引擎，没有模型也能回答；这是与通用规范的有意差异，说明写在悬停提示里。
- 必填项未填时「测试连接」「保存」禁用，并在按钮旁用文字写出原因（如「请先填写 API Key」「请先选择模型」），不只灰掉。
- 按钮禁用永远伴随原因；连接失败直接显示服务器给出的人话原因，不显示原始报错或堆栈。

## 证据呈现

- 「测试连接」成功显示「连接成功 · {延迟} ms · {模型}」；已连接状态显示测试时间与延迟，时间来自服务器 `testedAt`。
- 「获取模型列表」失败时提示「自动获取失败，已显示预置清单：{原因}」，并回退到预置模型；下拉里区分「预置」「已获取」「手动添加」三种来源。
- 徽标 = 首字母 + 稳定色点，性质同品牌色点（身份标识，不是 UI 状态色）。色值取 `brandColorOf(providerId)`（品牌扩展色板稳定哈希，不新增颜色），底色取 `brandTintBg` 的浅色；与状态色互不混用。
- 外链只用预置里的 `docsUrl`，新窗口打开并带 `rel="noreferrer"`。

## 响应式与可访问性

- 左列在 640px 以下收为顶部横向可滚动的列表，右列占满宽度（配置页既有 1280 最低宽度下保持左右布局）。
- 左列按 vertical tablist / tab 实现：上下方向键与 Home / End 移动，选中项 `aria-selected`，右列 `role="tabpanel"`；搜索框与各字段均有可访问名称。
- 徽标与色点 `aria-hidden`，状态文字对读屏可读。

## 例外

- 禁用发送按钮属于通用规范，这里有意不做（原因见上）。
- 密钥输入框保留时只显示掩码占位与「更换」，任何时候不回显已保存的密钥；测试连接时只在该项有未保存修改才随请求带上临时密钥 / 地址，否则测的是服务器上已保存的那份（服务器只在后者时记录测试结果）。
- 不提供单独的「停用」开关（固定交互未列）；「取消当前模型」由状态区的「改用本地引擎」完成（见文末补充）。`enabled=false` 的历史记录按「已停用」如实展示，保存即重新启用。
- 服务器在密钥 / 地址 / 模型变化时清空旧的测试结果（2026-11-27 起），旧的「已连接」不会挂在新配置上；前端保留本页内的「已保存，配置已变更，请重新测试」提示。
- 保存前的「测试连接」用的是表单里的临时密钥 / 地址，服务器不记录；因此保存后状态区显示「已保存，尚未测试」，保存前那条测试结果行同时清掉，避免两处说法打架。
- 「官方文档」「获取 API Key」都指向预置里的 `docsUrl`：预置注册表只有这一个网址，不另手写控制台地址。
- 即将支持的服务商（Anthropic）在左列表里可以点选看说明与文档链接，右列只有「暂不可配置」，不出表单。

## 补充（2026-11-27）：两个收尾入口

固定交互之外，状态区下方为已保存的服务商补了两个次要入口，都用 `type="link"` 的小号文字按钮，不与「测试连接 / 保存 / 设为当前模型」争视觉权重：

- **改用本地引擎**（仅当该家是当前模型时出现）：取消当前模型，Agent 回到本地确定性引擎。此前一旦设了当前模型就没有回退路径。
- **删除配置**：带确认（`Popconfirm`，危险色确认键），把这家在本机保存的配置连同密钥一起删除；它若正是当前模型则一并取消。此前密钥存进去后界面上没有办法清除。
