# 价格走势 / 量价走势 · 区间量尺与量价同骨架（Eason 2026-11-06 拍板）

> 设计权威：会话内高保真 `volume-margin-cost-hifi`（三轮评审定稿）。本文件只记实现要遵守的
> 规则和例外；视觉值见 `src/theme/tokens.ts` 的 `rangeRuler`。

## 目标

- 价格走势：在图上拖选一段时间，直接读出这段时间价格、销量怎么变（迪总会上点名要的能力）。
- 量价走势：和价格走势用同一套图（价格线 + 底部销量柱），只换内容层——不画竞品价格，
  加成本面积，销毛只进悬停卡。两页的拖选、量尺、标注完全一致。

## 范围

- 价格走势（合并图与分图面板）：`chart/PriceTrend/Chart.tsx`、`index.tsx`、`BrandLegendStrip.tsx`。
- 量价走势主品视图与组内对比的分离面板：每个面板改用价格走势的 `Chart`；组内对比的
  「合并单图」（MergedCompareChart）不在本轮范围，保持原样。
- 两个版本通道（stable / iterate）同时生效。

## 选区（两页同一套）

- 在绘图区（价格层或销量层）按下拖动即选区；拖动不足 4px 视为点击：有选区 = 清除，
  没有选区 = 原行为（月/季点击下钻）。拖完松手产生的 click 不再触发下钻。Esc 清除。
- 选区 = 浅蓝带（rgba(0,112,243,.06)）+ 左右 1px 竖线，纵向贯穿价格层和销量层；
  选区外白幕 .66 压淡。
- 时间胶囊挂在选区正上方（绘图区顶边之上），× 清除；胶囊正下方是读数方式切换
  「区间极差 | 区间涨跌」（会话态，默认区间极差）。按钮 title 写口径。
- 只选一个时间单位（起止同一桶）：不出量尺，胶囊下方换成琥珀提示「请选择周范围」
  （月 / 季粒度换字），只标这一桶的价格和销量。
- 选区态只留主品：主品以外的价格线、名称带药丸、价格数值标签都不显示；图顶对比品药丸
  降到 .45 透明度。悬停图顶某个对比品药丸 = 临时带出那条线，价格量尺切到它；销量尺
  始终量主品。Y 轴不变（按选区前的全部可见线算，拖选时主线不跳）。
- 选区态隐藏全局数值标签（价格三价标注、销量三点标注），只留量尺两端的数字。

## 量尺

- 区间极差：区间内最高与最低（与量价页 `periodSummary.rangeSpreadOf` 同口径：取最早的
  最高点、最早的最低点），率 = 极差 / 最低 × 100%，双向箭头。
- 区间涨跌：区间内最早、最晚的有效桶（缺采不插值），率 = (期末 − 期初) / 期初 × 100%，
  单向箭头从期初指向期末，率和数量带正负号。
- 价格有效 = 有价且 > 0 且未被异常守卫隔离；销量有效 = 非空。
- 极值点 = 小实心圆（r 3.5，系列色，白描边 1.2）+ 数值；价格点数值 13px、销量 11px，
  高点标上方、低点标下方（销量两点都标上方）。撞上胶囊 / 切换时挪到点的侧面。
- 每个点向量尺拉 1px 水平虚线（mute，dash 3 3），量尺竖线 + 箭头尖用 `rangeRuler.arrow`。
- 幅度框（2026-11-07 Eason「极差卡片用跟产品卡片一样的风格」，替代原浅灰底）：所有模式同一
  容器 = 悬停产品卡同款——白底 `rangeRuler.chipFill` + 1px `rangeRuler.chipBorder`（hairline）+
  圆角 `radius.card` 8 + `shadow.l2`（与 Chart 悬停卡 / 销毛迷你卡逐项同值，HTML 叠层渲染，
  不接指针）；高 40（描边内上下各 4px），左右内边距 10（同产品卡）。固定两行——
  第一行率（13px 600 墨色），第二行数量（11px body）；两行以框中线居中，框落在箭头中点；
  价格框与销量框同宽、同一条竖线。率算不出显示「—」；无波动显示 0.0% / ±0.0% + 0；
  只有 1 个有效桶显示「—」+「仅 1 个有效周」。
- 量尺列位置：选区右外侧优先 → 放不下翻到左外侧 → 都放不下（如全选）放选区内靠右。
  箭头短于 框高 + 12 时不画箭头，只留虚线连到框（方向由正负号表达）。
- 区间内某一层完全无数据：该层中间写「区间内无采集价格」/「区间内无销量数据」，不造点。
- 柱模式下两端极值柱加深到 .38。

## 图层标注

- 稳定版（head 版式，2026-11-07 三轮，Eason「标题还是不好」）：标题独占行，左缘 = 图左缘
  （轴列左缘，两标题同一条竖线），**不与任何刻度字同行、位置不随数据**。
  - 价格标题「价格 USD」（本币写币种代码；有成本写「价格 / 成本 USD」）在图顶行：调用方
    gridTop 计入 `PANE_HEAD_H`（20），标题与顶格刻度字之间留 8px。
  - 销量标题「销量 台」+「模拟」徽标在量带左上：价格最低刻度字（下探 8px）之下再留 8px。
  - 字号：名词 12px / 600 / ink，单位 12px / mute——高于 10px 刻度字与 11px 名称药丸一档。
  - 销量归属药丸留在名称带列、贴销量标题下；名称带只有一条线且就是归属品（量价页每面板）
    时与价格药丸同名，不重复出。
- 演进版（pill 版式）保持上一轮：名称带列内，价格标题贴最高名称药丸上方，销量标题贴量带顶。
- 成本面积在名称带有一颗「成本 · 模拟」药丸，纵向贴成本起点（两版式相同）。
- 分离面板（稳定版）：面板头行 10px（无药丸带，只留拖柄呼吸位）；共享轴列 paddingTop 与
  面板头行同源（滚动区 10 + 拖柄 14 + 面板头行），否则刻度整列与绘图区错位。

## 合并多组 · 量带归属切换（方案 B）

- 合并图选了多组主品时（2026-11-08 Eason 选型「主品切换」），量带同一时刻只画一个
  主品：柱色、上限（`volumeBandMaxOf`）、极值三点标注、区间量尺销量层、悬停量卡归属
  全部跟随 active 候选——语义与单组完全一致；分图/量价页每面板单归属，不受影响。
- 切换入口（双入口；名称药丸本体点击 = 隐藏/恢复语义不变）：
  ①销量归属药丸可点（描强调边 + ⇄），点击循环到下一组主品；
  ②名称带候选主品药丸右侧外挂「量」小按钮，点击直接指定；当前归属描强调边、
  `aria-pressed`。已归属品的「量」点击是 no-op。
- 悬停量卡：候选 ≥2 = 每个候选主品一行（归属色点 + 名称 + 当周销量 + 台），
  不切换也能横向比数；单候选保持原单行样式。
- active 落会话态 `dashboard.volumeOwnerKey`（跨页保留）；mains 变化后失效自动回落
  第一候选。

## 量价走势

- 每个面板一条价格线（该产品）+ 底部销量柱（恒为柱、恒开，不提供量开关）。
- 「销毛成本」开：价格层加成本面积（同价格走势销量面积做法：单调平滑、品牌色
  .17 → .02 纵向渐变、无描边，基线 = 价格层底），Y 轴把成本算进来；悬停主卡加脚行
  「当月成本 · 模拟 N」，上方销毛迷你卡显示「销毛率」。竞品面板无成本、无销毛卡。
- 「销毛成本」关：只有价格线 + 销量柱，与价格走势只留主品时同一几何。
- 档位带不画；线与柱用品牌色。组内对比仍锁定「销毛成本」（原行为）。

## 销量轴上限

- 两页量带上限改用细档取整 `volumeBandMaxOf`：最大值 × 1.1 后按 1 / 1.2 / 1.5 / 2 / 2.5 / 3 /
