# 量价走势 · 主产品阅读视图（volume-main-product）

> 局部决策文件。视觉权威：`design-proposals/pricelens-volume-spread-layout-demo.html`（单产品 mock）。
> 本页把它落到**每个面板**上（第一百六十七轮多面板架构不变），不回到单产品页。
> 上级契约：`PRODUCT.md`、`pricelens/DESIGN.md`、`docs/PRICE-LENS-DESIGN-HANDOFF.md`。

## 目标与范围

- 范围：`src/pages/VolumePrice.tsx` 与 `src/pages/volume/**`。页头、筛选条、AnalysisShell、
  ChartToolbar、PanelTimeTrack 等共享壳不在本面改动。
- 任务：按 demo 收口主产品（与组内对比）阅读视图——区间极差、尺寸标注尺、
  成本销毛带（模拟）、图下单周明细卡。
- 术语红线：UI 不出现「我司」；文案只用业务语义（「区间」「观察周」），不用工程语。

## 面板信息层级（自上而下）

1. 面板头：PillUnit（平台小药丸 + 产品名 + 配置 chip），主产品视图另有「本组对比（N）」。
2. 图表元信息行：左 = 图例（折后价粗线 / RRP 细线 / 销量色块，随价格口径开关显隐）；
   右 = 所选区间胶囊（起止锚日 + × 清除）或「拖动图表选择区间」提示（无选区时）。
3. 双极差卡并排（价格极差 / 销量极差）：百分比大数 + 绝对差值 + 最低—最高小字，
   aria-label 给完整读数；标题前有系列色短划；贴绘图区左右缘，放不下一起缩窄。
4. 主图：价格阶梯线（lineShape 随粒度）+ 销量柱（销量轴上限可编辑，行为保留）。
   选区 = 浅蓝底带 + 双侧竖线（selectAccent 低透明度）；区间极值画**尺寸标注尺**
   （垂直双箭头 + Δ 标签 + 白底标签框 + 从极值点引出的水平引线），价格尺在选区左、
   销量尺在选区右；极值点与观察点为空心圆。
5. 成本销毛带：成本阶梯线 + 销毛窄柱，标题「成本与销毛 · 金额/台」+ 灰底「模拟」tag；
   与主图共用时间轴与选区背景带；竞品整段无数据时显示空态文案。
6. 图下单周明细卡（三栏网格）：左 = 锚日/桶号 + 产品名与配置 + 「当前观察点 · 移出图表
   回到区间末周」；中 = RRP / 折后价 / 环比 / 销量；右 = 当月成本 / 单台销毛 / 销毛率，
   三格标签都带「· 模拟」。
7. 脚注行：「拖动选择区间 · 移动鼠标联动查看」+「价格 / 销量为周数据，成本 / 销毛为
   当月模拟值」（随粒度换「周/月/季」）。
8. 面板底部 PanelTimeTrack（同步/独立语义不变）。

## 交互与状态语义

- 观察列（activeIdx）= 悬停列 ?? 所选区间末周 ?? 窗口末桶。十字竖线贯穿主图 + 成本带，
  销量柱/销毛柱高亮、成本点、明细卡全部跟同一列；键盘 ←/→/Home/End 切换（走面板
  悬停通路，同步/独立联动语义不变）。
- 指针交互由面板自绘承接层（`volume/PointerShield.tsx`）接管：悬停列、拖选区间
  （按下即从单周起选，拖动扩展，松手提交）、横向参考位。图内不再出跟随浮层——
  时点读数只看图下明细卡（demo 同构）。
- 区间清除：元信息行胶囊的 ×（不依赖图内胶囊）。
- 缺采：价格/销量/环比显示 —，不插值、不借相邻桶；成本销毛悬停空桶 = gap（不借月）。
- 涨跌色：涨蓝（selectSoftInk/selectSoft）跌琥珀（#b45309/warningSoft），与全站 187 轮定案一致；方向同时由 ± 符号表达。

## 证据与数据状态

- 成本/销毛为当月模拟值：带内 tag、明细卡标签、脚注三处显式「模拟」，不靠颜色区分。
- 极差卡与标注尺只描述所选区间内的极值，不写成涨跌结论。

## 响应式与动效

- 面板为容器查询容器（`.lpl-volume-panel`）；面板 <640px 时明细卡改单列、说明行隐藏。
- 极差卡入场 160ms fade（`prefers-reduced-motion: no-preference` 才播放；全局 reduce
  规则兜底）。键盘焦点环 `.lpl-volume-stack:focus-visible` 与全站同款蓝色。

## 例外与有意取舍

- 2026-11-01 Eason 拍板确认：图内点击 = 选单周（不再清选区；清除只走区间胶囊 ×）；
  观察列回落 = 所选区间末周（无悬停/无选区才回窗口末桶）。
- 共享轴列与主图轴区的档位梯子顶部加「价格档位」常驻小标（2026-11-01 审计 P2-3：
  档位数字与 Y 刻度数字并排易混，此前只有悬停 title）；两处同款维护（SplitAxisColumn
  画在轴列顶部空气带、Chart.tsx 画在梯子上方空气带）。
- 尺寸标注尺的白底标签框钳制在绘图区内（clampRulerX，2026-11-01 审计 P2-4）：
  选区贴右缘时价格尺标签不压销量轴列、贴左缘时销量尺标签不溢出面板左缘。
- demo 的页头/导航/粒度切换器是 mock 壳，不搬（页面已有 PageHeader/FilterBar/AnalysisShell）。
- demo 明细卡 <760px 断点改按**面板宽**容器查询触发（多面板并排时视口宽不代表面板宽）。
- 极差卡宽 148px（demo 184px）：三面板并排的最小可读宽度（spreadCardRow 自动缩窄保左右对齐）。
- 标注尺与选区带颜色用系列色 + selectAccent 低透明度派生，不新增 token；demo 的
  独立「销量灰蓝」在多品牌面板里会与品牌色打架，按面板系列色统一。
- `src/chart/PriceTrend/Chart.tsx` 的 rangeBand / marginTip / tipBox 等量价专用 props
  随本次改版在量价页停用（明细卡与标注尺由面板层自绘），props 保留供其他调用方。
