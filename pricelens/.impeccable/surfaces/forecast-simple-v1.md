# 量价预测 · Lifecycle OS 简单版（forecast-simple-v1）

> 路由 `page = 'forecast'`（`pricelens/src/pages/ForecastPage.tsx`）。
> 依据：`docs/lifecycle-os-mvp/03-量价预测界面替换交接文档.md`、`docs/lifecycle-os-mvp/01-simple-complex-options.md`、`docs/lifecycle-os-mvp/02-simple-demo-simulation-data.md`。

## 目标

让经营者在单页内回答：当前无约束需求是多少；价格 / 促销 / 竞品事件各自贡献了什么方向的变化；可供量是否截断了实际 SO；预测结果对库存、DOS 和销毛意味着什么；哪些结论来自模型学习、业务假设或确定性计算。

## 范围与边界

- 只替换「量价预测」页；「量价走势」（`VolumePrice.tsx`、`src/pages/volume/**`）职责不变。
- 四个需求因子：需求基线、消费者感知价格（价格阶跃 + 可学习弹性）、促销事件（窗口脉冲 + 活动后一周）、竞品压力（上市后 6 周递减）。
- 供给只作 SO 上限（`SO = min(无约束需求, 可供量)`）；成本只进销毛链，不进需求。
- 竞品上市只作为我司份额压力事件，不自动判断扩盘 / 分流；页面显式显示「简单版只将其作为我司份额压力，扩盘比例待验证」。
- 数据为 24 周模拟（W1–W10 实际 + W11–W24 预测，R国 · 直营电商 · HUAWEI Pura 90 Pro 12+256GB，来源 demo_seed，版本 simple-demo-v1），整体状态 `simulated`；验模真值字段不进页面。
- What-if 只是本地草稿，不写入真实数据或外部系统；重置恢复基准。

## 信息层级（自上而下）

1. 范围与状态：全局筛选范围（国家 / 产业 / 币种）+ 演示口径 chip（R国 · 直营电商 · 产品 · W1–W24）+ `simulated` 文字徽标 + 模型版本 + 「让 Agent 解释」。
2. 经营摘要 KPI：当前周 SO、无约束需求、期末库存 + DOS、累计销毛、当前主要风险。
3. 逐周需求与成交图：无约束需求（蓝）、SO（华为红、最粗）、可供量（弱灰）三条主线；W1–W10 实线、W10 之后虚线；实际 / 预测分界线；缺货只表现为 SO 被可供量截断（红色环 + 文字标注）；图下接文字摘要。
4. 事件时间轴：上市 / 大促 / 供应波动 / 竞品上市 / 竞品促销 / 成本上调 / 清库促销七类事件行，图下方横排。
5. 本周预测变化：基线 → 价格 → 促销 → 竞品 → 供给截断的贡献瀑布，逐行带状态徽标（模型学习 / 业务假设 / 方向性判断 / 确定性计算），不写确定因果。
6. 周度经营主账：24 行表，周次 / 实际或预测 / 无约束需求 / 可供量（截断标）/ SO / 期末库存 / 单台销毛 / 事件；当前周高亮；草稿重算行有琥珀标记。
7. What-if 草稿：价格变化、促销强度增量、可供量变化三个滑杆 + 剩余预测 SO / 销毛变化 / 风险周读数 + 重置。
8. 因子与证据：每个因子的范围、窗口、形状、状态、证据来源与置信度。
9. 计算路径抽屉：输入事实 → 因子响应 → 无约束需求 → 供给截断 → 库存 / DOS / 销毛，含当周数值与公式。

## 状态语义

- 数据状态用文字徽标：`simulated`（琥珀 warningSoft / warningInk）；页内实际周 / 预测周用「实际」「预测」文字，不靠颜色单独表达。
- 因子状态四档文字：模型学习（蓝 soft）、业务假设（琥珀 soft）、方向性判断（灰）、确定性计算（描边墨）；置信度高中低文字并列。
- 缺货 = 截断：SO 等于可供量且低于无约束需求；用红色环 + 「截断」文字标签 + 摘要说明。
- 结论措辞区分事实 / 假设 / 确定性计算；竞品与促销贡献都写「方向性判断」，不写因果。

## 视觉

- 全部取自 `src/theme/tokens.ts`：白卡 `canvas` + `radius.card` + `shadow.l1`、页面 `canvasSoft` 底、hairline 分隔、控件 `radius.control`、间距 4/8/12/16/24。
- SO 线 `brandColor.HUAWEI` 最粗（3px）；无约束需求 `color.link` 2px；可供量 `color.hairlineStrong` 1.6px 弱参照；不新增 token、不使用渐变 / 发光 / AI 紫。
- 数字一律 `tnum`；周次等标识用现有 `mono` 类；价格整数 `$` 千分位。
- 不引入第二套顶栏：页面自挂一套 `PageHeader` + `data-lpl-scroll` 滚动容器（维持 forecast 现状，不进 `AnalysisShell`）。

## 响应式与可访问性

- 桌面高密度；图卡与主账表在窄视口局部横向滚动（`overflowX: auto` + minWidth），不裁关键数值。
- 滑杆 / 按钮均有可见文字标签、`aria-label` / `ariaLabelForHandle`，键盘可聚焦；抽屉用 antd Drawer（焦点管理内建）。
- 图表 `role="img"` + 完整文字 aria-label，图下必有文字摘要或表格替代；不依赖动画传递状态（仅滑杆联动即时刷新，无位移动画）。

## 例外与决策记录

- UI 不出现「我司」字样（114 轮铁律，2026-11-01 Eason 拍板）：交接文档引文中的
  「我司份额压力」一律改写为「华为份额压力」（DriverWaterfall 边界句、E04 事件
  detail、竞品因子 boundary 三处已改）。
- 演示 fixture 不随全局国家 / 币种筛选变化（固定 R国 · USD 模拟）：范围行显式
  给出「币种 USD（固定）」chip，全局筛选范围行只展示国家 / 产业（全局币种对本页
  数据无效，展示反而误导），页首边界说明保留。
- 逐周图不画区间带：fixture 只有点估计（P50），无残差 / 分位数字段，画带即造数
  （03 交接文档允许「只展示点预测」，要求说明来源——图下摘要已声明「区间暂以
  历史残差带估计、未做分位数校准，本图不绘制区间」）。接入真实模型输出 P10/P90
  后再补画。
- ChartContentBar（价格走势 / 量价走势 / 量价预测三页签）挂在本页 PageHeader 之下，
  与另两个图表页同款；页头管理页签的「量价预测」入口保留（双入口并存，主导航
  唯一选中规则不受影响）。
- What-if 只作用于预测窗口（W11–W24），实际周（W1–W10）不可被草稿改写。
- 旧口径「固定基准需求 4,600 / 弹性 −1.85 / 供应上限 7,200」及其黑箱乘数（大盘趋势、竞品修正百分比）全部移除；旧纯函数测试迁至 `src/pages/forecast/__tests__/forecastModel.test.ts` 并按简单版因子扩展。
